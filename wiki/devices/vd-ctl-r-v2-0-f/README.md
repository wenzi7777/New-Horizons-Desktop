# TIA-CTL v2.0.F

TIA-CTL v2.0.F（板上絲印 `TIA-CTL/A v2.0.F 2026.10`）的硬體參考入口。以下只列已能在 2026-11-11 的 EasyEDA 最終匯出（PCB 網路表）核對的事實；操作流程與實測數值不在此推定。

## 與 v1.5.F 相同

- 主控 ESP32-S3 MINI-1 N8；14 × 14 矩陣：列為 GPIO1–14，行為 GPIO17、18、21、26、47、33、34、48、35、36、37、38、39、45。
- BQ25180 充電、MAX17048（TDFN）、BMI270、BMM350、動作按鈕、兩顆狀態 WS2812B（System / Battery）、9 顆外接 LED（GPIO16）。
- 韌體腳位表與 v1.5.F 共用。

## v2.0.F 新增或改變

| 項目 | 內容 |
|---|---|
| Vref | MCP4725 DAC（I²C 0x60，A0 接地）→ 1 kΩ → Vref 節點（運放正輸入、100 nF）。開機與重啟後固定為 330 mV；板上**沒有任何腳位能回讀 Vref**。 |
| 校準開關 | PCA9536（I²C 0x41）IO0 → Q1（DMG1012T，閘極 2.2 kΩ 下拉）。Q1 導通時，14 顆 10 kΩ 0.1 % 電阻把各 GIN 接到 CAL 並下拉。IO1–IO3 未接。 |
| Rfb | 背面 Rfb0–Rfb13 的 0805 焊盤，出廠不焊；阻值由使用者自選。 |
| GPIO45 | R27 100 kΩ 下拉（開機設定腳）。Vref 高於約 0.8 V 時重啟有開機失敗的風險。 |
| 電池 | 背面側壓彈片（1 GND / 2 VBAT / 3 BAT_ID）；正面備用 JST（CN2，預設不貼）。BAT_ID 接 GPIO15，R3 + R5 共 200 kΩ 上拉；電池端的 ID 電阻 39 k / 68 k / 100 k / 150 k 對應 200 / 400 / 500 / 600 mAh，沒有電阻（JST）時改為手動設定。 |
| USB | 只有一個 USB-C（USB2）；背面電池 USB-C 已移除。 |

韌體只在開機時讀一次 BAT_ID（GPIO15 為 ADC2，與 Wi-Fi 共用）。
