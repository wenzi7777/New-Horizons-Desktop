# TIA-CTL v2.0.F

TIA-CTL v2.0.F(基板シルク `TIA-CTL/A v2.0.F 2026.10`)のハードウェア参照です。2026-11-11 の EasyEDA 最終エクスポート(PCB ネットリスト)で確認できた事実のみを記載し、手順や実測値は推定しません。

## v1.5.F と同じ点

- ESP32-S3 MINI-1 N8。14 × 14 マトリクス:行は GPIO1–14、列は GPIO17、18、21、26、47、33、34、48、35、36、37、38、39、45。
- BQ25180 充電、MAX17048(TDFN)、BMI270、BMM350、アクションボタン、ステータス WS2812B 2 個(System / Battery)、外部 LED 9 個(GPIO16)。
- ファームウェアのピン表は v1.5.F と共通です。

## v2.0.F での追加・変更

| 項目 | 内容 |
|---|---|
| Vref | MCP4725 DAC(I²C 0x60、A0 は GND)→ 1 kΩ → Vref ノード(オペアンプ非反転入力、100 nF)。電源投入後と再起動のたびに 330 mV 固定。**Vref を読み戻せるピンはありません。** |
| 校正スイッチ | PCA9536(I²C 0x41)IO0 → Q1(DMG1012T、ゲートは 2.2 kΩ でプルダウン)。Q1 が ON のとき、10 kΩ 0.1 % 抵抗 14 本が各 GIN を CAL に接続します。IO1–IO3 は未接続。 |
| Rfb | 裏面の Rfb0–Rfb13(0805 パッド)。出荷時は未実装で、値はユーザーが選びます。 |
| GPIO45 | R27 100 kΩ プルダウン(ブートストラップ)。Vref が約 0.8 V を超えると再起動時に起動失敗の恐れがあります。 |
| バッテリー | 裏面のサイドプレス ばね接点(1 GND / 2 VBAT / 3 BAT_ID)。表面に予備の JST(CN2、標準は未実装)。BAT_ID は GPIO15、R3 + R5 = 200 kΩ のプルアップ。電池側の ID 抵抗 39 k / 68 k / 100 k / 150 k が 200 / 400 / 500 / 600 mAh に対応し、抵抗が無い場合(JST)は手動設定です。 |
| USB | USB-C は 1 つ(USB2)。裏面のバッテリーモジュール用 USB-C はありません。 |

ファームウェアは BAT_ID を起動時に 1 回だけ読みます(GPIO15 は ADC2 で Wi-Fi と共有)。
