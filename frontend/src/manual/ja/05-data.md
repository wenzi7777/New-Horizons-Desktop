# 記録データと分析

## CSV エクスポート

**CSV エクスポート**には、このサーバーに保存されたすべての記録があります。

記録 1 回につき 1 フォルダーです。

```
<デバイス UID>/<日付>/<時刻>/
  <時刻>.data.csv     センサーデータ
  <時刻>.events.csv   アプリのイベント（ある場合のみ）
  <時刻>.meta.json    デバイスと記録の情報
```

フォルダー名の日付と時刻は UTC です。

- フォルダーはダブルクリックで開き、ファイルはダブルクリックでダウンロードします。
- フォルダー横の zip ボタンでフォルダーごとダウンロードできます。
- 記録を選ぶと、右側にタイムラインと情報が表示されます。
- 分析ボタンで**ツール**の**データ分析**に開きます。

## データ分析

**ツール**から**データ分析**を開きます。このサーバーの記録を選ぶか、パソコンにある `.data.csv` を開きます。

表示される内容：

- 記録の長さ、サンプリングレート、フレームの欠落の有無。
- 合計圧力、最大値、接触面積の推移。グラフをドラッグすると拡大、ダブルクリックで全体表示に戻ります。
- カーソル位置のヒートマップ、または選んだ範囲の平均・最大。
- 全センサーの表。ヒートマップか表でセンサーをクリックすると、グラフに表示されます（最大 8 個）。
- IMU のデータとアプリのイベント（記録に含まれる場合）。

**範囲を書き出し**で、拡大した部分だけを新しい CSV として保存できます。

## センサー番号

センサーは左上から行ごとに P1、P2、… と番号が付きます。CSV の列、ヒートマップ、プロファイルエディターで同じ番号を使います。
