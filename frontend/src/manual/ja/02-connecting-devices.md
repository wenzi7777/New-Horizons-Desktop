# デバイスの接続

デバイスはこのアプリに直接はつながりません。次のどちらかを経由します。

| | Gateway | Hub |
| --- | --- | --- |
| 中身 | パソコンで動かすソフトウェア | 小型のボード |
| デバイスのつなぎ方 | Wi-Fi（パソコンと同じネットワーク） | ESP-NOW（デバイス側に Wi-Fi 不要） |
| 向いている場面 | 研究室のネットワーク上のデバイス | ウェアラブル、Wi-Fi が使いにくい場所 |

どちらも接続されると**リレー**ページに表示されます。設定手順はそのページの一番下にもあります。

## Gateway の設定

1. **リレー**ページの Gateway 欄で**ダウンロード**をクリックし、デバイスと同じ Wi-Fi にあるパソコンで展開します。
2. `python3 scripts/start.py` を実行します。初回に設定ファイルが作られます。
3. そのパソコンで `http://127.0.0.1:5052` を開き、Gateway ID を設定してオンにします。

## Hub の設定

1. Hub の電源を入れ、スマートフォンかパソコンで `NHHub-…` という Wi-Fi に接続します。
2. `http://nhos.hub` を開き、Wi-Fi と接続先サーバーを入力します。
3. Hub が再起動し、**リレー**に表示されます。カードの**管理**から名前の変更、アップデート、設定変更ができます。

## デバイスの接続先を設定する

新しいデバイスやリセットしたデバイスは、`NHOS-…` という設定用ネットワークを出します。

1. `NHOS-…` に接続し、`http://nhos.os` を開きます。
2. **接続方法**で「Wi-Fi 経由で Gateway に接続」（Wi-Fi を選んでパスワードを入力）か「近くの Hub に直接接続」を選びます。
3. **接続**を押します。デバイスが再起動し、数秒で**ホーム**に表示されます。

あとから別の Wi-Fi に移すときは、デバイスの設定で**再起動して Wi-Fi 設定へ**を使います。

## デバイスが表示されないとき

- Gateway：**リレー**で Gateway がオンラインか、パソコンとデバイスが同じネットワークにあるかを確認します。
- Hub：Hub がオンラインか、デバイスが Hub から数メートル以内にあるかを確認します。
- 共通：デバイスを再起動します。それでも表示されない場合は、`NHOS-…` に接続し直して設定を確認します。
