# デバイスと設定

## ホーム

**ホーム**には接続したことのあるデバイスがフォルダーに分けて表示されます。フォルダーは**オンライン**、**オフライン**と、設定したグループごとです。フォルダーをクリックするとデバイスが表示され、デバイスをクリックすると設定が開きます。

デバイスのカードには、**可視化**（リアルタイムのデータ）、**デバイスファイル**（デバイス内のファイル）、**詳細コマンド**（コマンドの手動送信）、**デバイス Wiki**（そのボードの資料）のボタンもあります。

## デバイスの設定

設定ページの左に項目の一覧があります。

| 項目 | 内容 |
| --- | --- |
| 概要 | 名前、グループ、ファームウェアのバージョン、バッテリー、接続経路 |
| メンテナンス | 校正 |
| アプリ | デバイスにインストールされたアプリ |
| ハードウェア | LED、ディスプレイ、バッテリー容量と充電、アクションボタン（v1.5.F のみ） |
| ストリーミング | スキャン速度、ストリーミング、IMU、デバイスの時刻をどこから取るか |
| アップデート | ファームウェアのアップデートと更新チャンネル |
| 診断 | 稼働記録、スキャンと送信の統計、メモリ |
| ファイル | デバイス内のファイルとログ |
| 実験的 | テスト用の設定。通常はオフのままにします |

複数のデバイスをホームで同じフォルダーにまとめるには、**概要**で同じグループを設定します。

## 校正

校正は**メンテナンス**にあります。方法は 3 つです。

- **ゼロ点調整**：センサーから荷重をすべて外して実行します。以降の値は 0 から始まり、単位は mV です。
- **逐点校正**：無負荷の基準値を取り、既知の圧力（おもりなど）を 1 段ずつ加えて記録します。以降の値は kPa になります。各センサーに 3 段以上必要です。
- **気圧校正**：研究室の圧力チャンバーが段階的に圧力を変え、全センサーを一度に校正します。

一番下の**校正データと設定**で、校正のオン・オフ、書き出し、消去ができます。

## ファームウェアのアップデート

**アップデート**でアップデートを確認して適用します。完了するとデバイスが再起動します。

**安定版**は通常のリリース、**ベータ版**はテスト中のリリースを先に受け取ります。テストを頼まれていなければ安定版のままにしてください。
