# はじめに

NH Console では、圧力センサーデバイスのデータをリアルタイムで表示・記録し、デバイスの設定を行います。

## ログイン

管理者から受け取ったアカウントでログインします。アカウントは 2 種類あります。

| アカウント | 使える機能 |
| --- | --- |
| admin | すべて：ホーム、可視化、リレー、プロファイル、CSV エクスポート、アプリ、スタジオ、ツール |
| user | 可視化とプロファイル |

研究室のアカウントは共有なので、アカウント名を個人の名前としては扱いません。

## 上部のバー

- **左**：**Console** とバージョン番号をクリックすると、バージョン、研究室、各バージョンの更新履歴が表示されます。
- **中央**：各ページへのリンクです。表示されるページはアカウントによって異なります。
- **右**：太陽／月のボタンでライトとダークを切り替えます。**自動**（太陽と月が半分ずつのアイコン）は会津の日の出・日の入りに合わせて切り替わります。クリックするたびに ライト → ダーク → 自動 の順に変わり、選んだ設定はこのブラウザに保存されます。本のアイコンでこのマニュアルを開きます。その隣は言語の切り替え（English、日本語、简体中文）、アカウント、**ログアウト**です。

## 最初の手順

1. Gateway か Hub を通してデバイスをつなぎます。「デバイスの接続」を参照してください。
2. **ホーム**にデバイスが表示されることを確認します。
3. **可視化**でデータを見て、記録します。
4. 記録したデータは **CSV エクスポート**と**ツール**でダウンロード・分析します。
