# Profiles, apps and other tools

## Profiles

A profile draws a device's sensors on a picture, such as an insole or a glove.

1. Open **Profile** and create a new profile.
2. Upload a background image.
3. Click on the image to place sensors, and set which matrix channel each one is.
4. Choose the default view (2D or 3D) and press **Save**.

Then pick the profile on a device's card in **Visualize**.

## Apps

Devices can run small apps (for example a step counter or a display page).

- **Apps** is the app store: pick an app and a device to install it. Scanning pauses during the install and resumes afterwards.
- The **Apps** section of a device's settings shows what is installed on it.
- **Studio** is where apps are written and tested on a simulated device before installing them.

## Tools

**Tools** has utilities for experiments, such as **Data Analysis** and the pressure chamber controls.

## Advanced commands

The **Advanced Commands** button on a device card opens a terminal for that device. Paste a command and run it. This is for maintenance; normal settings are all in the settings page.
