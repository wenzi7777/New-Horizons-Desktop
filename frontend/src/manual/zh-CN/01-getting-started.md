# 开始使用

NH Console 用来实时查看、录制压力传感设备的数据，并对设备进行设置。

## 登录

用管理员给你的账号登录。账号分两种：

| 账号 | 可以使用的功能 |
| --- | --- |
| admin | 全部：首页、可视化、中继、配置、CSV 导出、应用、工作室、工具 |
| user | 可视化和配置 |

实验室的账号是共用的，所以应用不会把账号名当作你的名字。

## 顶部栏

- **左侧**：点击 **Console** 和版本号，可以查看版本、实验室信息和每个版本的更新日志。
- **中间**：各个页面。能看到哪些页面取决于账号。
- **右侧**：太阳／月亮按钮切换浅色和深色。**自动**（一半太阳一半月亮的图标）跟随会津的日出日落切换；每点一下按 浅色 → 深色 → 自动 的顺序切换，选择会记在这个浏览器里。书本图标打开本手册。旁边是语言选择（English、日本語、简体中文）、账号和**退出登录**。

## 从哪里开始

1. 通过 Gateway 或 Hub 连接设备，见“连接设备”。
2. 确认设备出现在**首页**。
3. 在**可视化**里查看实时数据并录制。
4. 在 **CSV 导出**和**工具**里下载、分析录制的数据。
