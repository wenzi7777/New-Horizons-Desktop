# 录制数据与分析

## CSV 导出

**CSV 导出**里是保存在这台服务器上的所有录制。

每次录制是一个文件夹：

```
<设备 UID>/<日期>/<时间>/
  <时间>.data.csv     传感器数据
  <时间>.events.csv   应用事件（有事件时才有）
  <时间>.meta.json    设备与录制信息
```

文件夹名里的日期和时间是 UTC。

- 双击文件夹打开，双击文件下载。
- 文件夹旁的 zip 按钮可以下载整个文件夹。
- 选中一次录制，右侧会显示时间轴和信息。
- 分析按钮会在**工具**的**数据分析**里打开这次录制。

## 数据分析

打开**工具**，再打开**数据分析**。可以选择这台服务器上的录制，也可以打开电脑上的 `.data.csv`。

可以看到：

- 录制时长、采样率、是否丢帧。
- 总压力、峰值和接触面积随时间的变化。在图上拖动可以放大，双击回到全部。
- 光标处的热力图，或所选范围的平均值、峰值。
- 所有传感器的表格。在热力图或表格里点击传感器，就会画到图上（最多 8 个）。
- IMU 数据和应用事件（录制里有的话）。

**导出范围**把放大的那一段另存为新的 CSV。

## 传感器编号

传感器从左上角开始逐行编号为 P1、P2……。CSV 的列、热力图和配置编辑器使用相同的编号。
