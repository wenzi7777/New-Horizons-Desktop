# 连接设备

设备不会直接连到本应用，而是经过下面两种中继之一：

| | Gateway | Hub |
| --- | --- | --- |
| 是什么 | 装在电脑上的软件 | 一块小板子 |
| 设备怎么连 | Wi-Fi，与电脑在同一网络 | ESP-NOW，设备不需要 Wi-Fi |
| 适合 | 实验室网络里的设备 | 穿戴设备、Wi-Fi 不好用的地方 |

两者连上后都会出现在**中继**页面。设置步骤也写在该页面的最下方。

## 设置 Gateway

1. 在**中继**页面的 Gateway 一栏点击**下载**，在与设备同一 Wi-Fi 下的电脑上解压。
2. 运行 `python3 scripts/start.py`。第一次运行会生成设置文件。
3. 在这台电脑上打开 `http://127.0.0.1:5052`，设置 Gateway ID 并启用。

## 设置 Hub

1. 打开 Hub 电源，用手机或电脑连上名为 `NHHub-…` 的 Wi-Fi。
2. 打开 `http://nhos.hub`，填入 Wi-Fi 和要连接的服务器。
3. Hub 重启后会出现在**中继**页面。点击卡片上的**管理**可以改名、更新或修改设置。

## 让设备连到中继

新设备或重置过的设备会开启一个名为 `NHOS-…` 的设置网络。

1. 连上 `NHOS-…`，打开 `http://nhos.os`。
2. 在连接方式里选择“通过 Wi-Fi 上的 Gateway”（再选择 Wi-Fi 并输入密码）或“直接连附近的 Hub”。
3. 按下连接。设备会重启，几秒后出现在**首页**。

之后要换到别的 Wi-Fi，在设备设置里使用**重启并进入配网**。

## 设备没有出现时

- Gateway：在**中继**页面确认 Gateway 在线，并确认电脑和设备在同一网络。
- Hub：确认 Hub 在线，设备离 Hub 在几米以内。
- 两者都适用：重启设备。如果还是没有出现，重新连上 `NHOS-…` 检查设置。
