# 设备与设置

## 首页

**首页**按文件夹列出连接过的所有设备：**在线**、**离线**，以及你设置的每个分组各一个文件夹。点击文件夹查看里面的设备，再点击设备打开它的设置。

设备卡片上还有这些按钮：**可视化**（实时数据）、**设备文件**（设备里的文件）、**高级命令**（手动发送命令）、**设备 Wiki**（这块板子的资料）。

## 设备设置

设置页面左侧是分类列表。

| 分类 | 内容 |
| --- | --- |
| 概览 | 名称、分组、固件版本、电量、连接方式 |
| 维护 | 校准 |
| 应用 | 设备上安装的应用 |
| 硬件 | LED、显示屏、电池容量和充电、动作按钮（仅 v1.5.F） |
| 数据流 | 扫描速率、数据流、IMU、设备的时间从哪里来 |
| 更新 | 固件更新和更新通道 |
| 诊断 | 运行记录、扫描和发送统计、内存 |
| 文件 | 设备里的文件和日志 |
| 实验性的 | 测试用的设置，平时保持关闭 |

想让几台设备在首页放进同一个文件夹，就在**概览**里给它们设置相同的分组。

## 校准

校准在**维护**里，有三种方式：

- **归零**：把传感器上的负载全部拿掉后执行。之后读数从 0 开始，单位是 mV。
- **逐点校准**：先采集无负载的基准，再逐级加上已知压力（例如砝码）并采集。之后读数单位是 kPa。每个传感器至少需要 3 级。
- **气压校准**：由实验室的压力舱逐级改变压力，一次校准所有传感器。

最下方的**校准数据与设置**可以开关校准、导出或清除。

## 更新固件

在**更新**里检查并应用更新，完成后设备会重启。

**正式版**接收正常发布的版本，**测试版**会先收到测试中的版本。除非被要求测试，否则请保持正式版。
