# v0.28.0

**診斷頁重新設計：裝置健康和掃描狀態改成「摘要數字＋分組清單」，並顯示 ADC 校正點與讀取錯誤。**

## 診斷頁

- **裝置健康卡片**：
  - 有異常時，原因會條列在最上面（不再擠成一行）。
  - 接著是四個摘要數字：累計通電、開機次數、異常重開、晶片溫度（附最低到最高的範圍）。
  - 下面依「時間 / 開機與重開 / 韌體 / 環境與連線」分組，每組是左邊標籤、右邊數值的清單。
  - 重開原因改用文字顯示（例如「上電」「重啟命令」「任務看門狗」「欠壓」），當機、看門狗、欠壓等異常的重開會標紅。
- **掃描與發送卡片**（取代原本的「流背壓」）：
  - 摘要數字：掃描速率（附目標 fps）、超時影格、發送失敗、ADC 讀取錯誤。
  - 分組：掃描時序、掃描啟動延遲、ADC 讀取、發送、網路。
  - 掃描啟動延遲改成長條圖，看得出延遲集中在哪個區間。
  - 時間單位自動在 µs 和 ms 之間切換；RSSI 附上訊號好壞的描述。
  - 只有需要注意的數值會上色（例如實際掃描比目標慢 5% 以上、有超時或發送失敗）。
- **ADC 讀取**（需要韌體 v1.16.1）：ADC1、ADC2 各一行，列出目前 layout 用到哪幾條 A 線、這顆晶片的 eFuse 校正點，以及開機以來的讀取錯誤次數。舊韌體會顯示「此固件未回報」。
- 掃描效能卡片上原本英文的「Health」按鈕改為「刷新」。

Companion firmware release: **New Horizons OS v1.16.1**.
