# v1.2.2

**Relays 頁面的名稱統一為 NH Gateway / NH Hub；拿掉沒有作用的 Hub 分組。**

## Relays 名稱

- 卡片標題、管理視窗和刪除確認一律顯示 **NH Gateway** 或 **NH Hub**，旁邊附上 ID。
- 以前顯示的是 Gateway 自己回報的 `gateway_name`。這個值存在每台 Gateway 的 `.run/config.json`，不同版本安裝留下的預設值不同（`New Horizons Gateway`、`NHOS Gateway`），同一頁面會出現兩種名字。現在不再採用這個值，靠 ID 區分每一台。
- 三語文案裡的 "New Horizons Gateway / Hub" 也改成 NH Gateway / NH Hub。

## 移除 Hub 分組

- 拿掉 Hubs 區塊的分組顯示與說明文字。這個功能從來沒有建立或指派分組的介面，所有 Hub 都落在「未分組」。
- Backend 一併移除 `/api/hub-environments`、`/api/gateways/<id>/environment` 與頻道衝突比對。頻道由 Hub 連上的 AP 決定，無法分配，衝突偵測幫不上忙。
- Hub 管理視窗的頻道顯示保留，改成直接記在 relay 資料裡：心跳沒帶頻道時沿用上一次的值，離線時歸零。
- 舊的 `_newhorizons_hub_environments.json` 不再讀取，可以手動刪除。

## 相容性

- 搭配 Gateway v1.1.2（同日發布，預設名稱改為 NH Gateway）；舊版 Gateway、Hub 照常運作。

Companion firmware release: **New Horizons OS v1.17.1**.
