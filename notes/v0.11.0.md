# v0.11.0

App Studio 支援韌體 v1.4.0 的 **OLED 與 Action Button**：App 可以在 OLED 上顯示數值與比例條，並用按鈕換頁。

## NHS 新語法

內建的 SDK 同步至 App Library `ded9dd8`：

```
show <row> "<label>" <expr> [digits <n>]      # 一行：標籤 + 數值
bar  <row> "<label>" <expr> range <lo>..<hi>  # 一行：標籤 + 比例條
button()                                      # 每次短按只有一幀為 true
a % b                                         # 取餘數，用來換頁
```

用到這些語法的 App 會自動標示需要 `min_os: v1.4.0`。編輯器的語法上色、自動完成與「參考」分頁都已加入新語法與 OLED 的限制（第 0–3 行、標籤 10 字、小數 0–3 位）。

## 模擬器

- 新增 **OLED 預覽**：顯示的內容與裝置的「應用」頁逐字、逐像素一致（格式化由 SDK 的 `oled.mjs` 計算，與韌體的 `AppDisplay.cpp` 相同）。
- 新增「**按下按鈕**」：
  - 即時模式：送到串流的下一幀，與實機相同。
  - 錄製檔模式：按壓依幀記錄，往回拖時間軸再播放也不會消失，事件時間軸也一併重算；可一鍵清除。
- 節點列表會標示 OLED 節點畫在哪一行。

## 裝置設定

OLED 頁面新增「**應用**」（アプリ／应用）。App 的內容只在選擇這一頁時顯示，已安裝的 App 不會自己佔用螢幕。Terminal 的 `set-oled` 也可以選擇。

## 修正

- **後端會拒絕使用 OLED 或按鈕的 App**：後端的套件檢查不認得 `button`、`display` 兩個 capability 與 4 個新 op，這類 App 安裝時會以 `unknown_capability` 失敗。已補上，並新增測試：後端的 op 與 capability 清單必須和內建 SDK 完全一致，之後 SDK 新增 op 時不會再漏掉。

## 驗證

Python、frontend 測試全數通過；`npm run build` 通過。OLED 預覽已以伺服器端算繪成圖片確認換頁與比例條。實機上的 OLED 顯示尚未驗證。

Companion firmware release: **New Horizons OS v1.4.0**.
