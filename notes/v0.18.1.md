# v0.18.1

**逐點手動校正改成「新增等級 → 選擇等級 → 擷取」，每個等級的感測器圖如實顯示擷取狀態。**

## 校正工作台（Device Settings → 維護）

- **新增等級按鈕**：輸入壓力後按「新增等級」（或 Enter）建立等級，不再是「改壓力再擷取」才隱含地產生新等級。
  - 新等級在第一次擷取前標示「未擷取」。
  - 輸入已存在的壓力會提示並直接選中它；0 以下會提示錯誤。
- **等級清單就是選擇器**：選中的等級會高亮，每列顯示擷取進度並可刪除。
- **感測器圖跟著選中的等級**：
  - 標題顯示「等級 X kPa · 已擷取 n/N」。
  - 在矩陣上選感測器後按「擷取 Pn」，完成後自動跳到這個等級下一個還沒擷取的感測器；「擷取全部感測器」也作用在選中的等級。
- **如實顯示擷取狀態**：
  - 每個等級各自保存感測器狀態，不會沿用上一個等級的圖。
  - 顯示的已擷取數和裝置回報不一致時（例如切換等級，或用 Terminal 擷取過），會向裝置重新讀取；讀取期間矩陣變淡並暫停擷取。
  - 圖下方加上圖例：已擷取／尚未擷取。
- 說明文字改成新流程，並寫明每個感測器至少要 3 個等級才能擬合。
