# v1.13.0

**基準電壓 (Vref) 改成「手動 + 兩個開關」，錄製檔記下 v2.0.F 的讀取方式；FindMe 卡片不再在兩組值之間跳動。**

## 基準電壓 (TIA-CTL v2.0.F)

- 原本的 Raw / 仮想 Rfb / 自動 三段按鈕改成兩個開關：「換算到基準刻度」（仮想 Rfb）與其上的「智慧 Vref 調節」（自動）。兩個都關就是手動（Raw），和 v1.5.F 以前的板子讀法相同；換算需要先量測 Rfb，智慧調節需要換算開著，讀數的刻度才不會跟著 Vref 變。韌體的三種模式不變。
- 手動時照舊有 Vref 滑桿與安全色帶；手動且 Vref 為 330 mV 時會註明「與 v1.5.F 以前的板子同刻度」。智慧調節時不再顯示鎖住的滑桿，改為顯示目前 Vref 與開機後調整次數。
- 基準 Rfb、GPIO45 漏電補償移到「詳細設定」，和 Rfb 量測、校正開關、上限、Vref 掃描放在一起。

## 錄製

- `.meta.json` 新增 `range`：`mode`、`vref_mv`、`ref_rfb_ohm`、`leak_compensation`、各列 `rfb_ohm` 與 `offset_mv`。只有 v2.0.F 會有，其他板子為 `null`。錄製中途改模式、Vref、基準 Rfb 或漏電補償會記在 `changes`，之後就能分辨哪段資料可以和舊板直接比較。

## FindMe

- 設備設定的 FindMe 卡片不再在兩組值之間跳動（Gateway 主機一下是設備自己的 IP、一下是 relay 的 IP；最終成功一下是時間、一下是數字）。原因是 relay 的在線快照把設備 IP 與時間寫進了設備自己用來回報 relay 位址與開機後毫秒的欄位；relay 那份改存在 `device_addr`、`last_findme_at`。
- 「最終成功」改為「開機後 N 秒」。

## 設備設定

- 開關類設定（IMU、串流緩衝、自訂 Manifest、開機自動更新、Log、濾波、Raw ADC、漏電補償，以及外部 LED 模式）改用和 App 相同的開關元件。
- IO 視覺化工具加入 v2.0.F 的板子圖。
- App：執行中卡片除了 OLED 與狀態燈，也顯示外部 LED 燈條（有 `drive_ext_led` 權限的 App）；多個 App 都可能點燈時標示「共用」，外部 LED 模式不是 App 時提示實體燈條不會亮。按鈕的圖示改為置中。
