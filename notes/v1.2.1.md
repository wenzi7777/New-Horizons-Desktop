# v1.2.1

**Gateway 可以拒絕遠端管理了，Desktop 會照實顯示。**

## Gateway 管理

- Gateway v1.1.0 新增「接受遠端管理」開關（在 Gateway 本機 WebUI，預設開啟）。
- 關閉時，Gateway 管理視窗只剩總覽，並提示到 Gateway 本機 WebUI（`http://127.0.0.1:5052`）開啟。
- 管理視窗開著時對方才關掉的話，按下操作會顯示同一句提示，不再只顯示 `remote_management_disabled`。

## Backend

- 記錄 Gateway 回報的 `remote_management`；沒有回報的舊版 Gateway 視為允許。

## 相容性

- 搭配 Gateway v1.1.0（同日發布，本機 WebUI 也改成跟這裡的 Gateway 管理視窗同一套版面）。
- 舊版 Gateway 照常運作。

Companion firmware release: **New Horizons OS v1.17.1**.
