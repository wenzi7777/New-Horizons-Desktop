# v1.13.2

**A setting no longer flips back to its old value a moment after you change it; on/off settings are "On / Off" selects again, and everything is sent with Apply.**

## Settings flipping back

- For a device connected through NH Studio, Pocket, headless or a Hub, the replies to setting commands (`set_range`, `set_vref`, `set_imu` …) never reached the device's status: the new value showed right after, then the next command's reply brought back the value from the last poll until the page was reloaded (the device had changed all along). A successful setting reply now writes its vref, range, imu, filter, stream_buffer, matrix_layout, action_button, indicators, battery, power, logging or ota block into the status; a refused command writes nothing.

## Switches back to selects

- Device settings: IMU, stream buffer, custom manifest, update on boot, log, filter and raw ADC are "On / Off" selects again, and the external LED mode is its old select; each section's Apply button sends them as before.
- Reference voltage (TIA-CTL v2.0.F): "convert to the reference scale" and "smart Vref" are two selects sent together with one Apply (turning conversion off turns smart off too); GPIO45 leak compensation is a select sent with the reference Rfb's Apply.
- Apps: turning an app on a device on or off is a select plus Apply instead of taking effect on the switch.
