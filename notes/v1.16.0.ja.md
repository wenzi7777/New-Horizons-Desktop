# v1.16.0

**新しい「イラスト」表示：デバイスの概要がボードの図になり、ライブ値が実際の部品から引き出し線で示されます。既定はこれまでどおりクラシック表示で、上部バーで切り替えられます。**

## イラスト表示（v2.0.F / v1.5.F / v1.0.F）

- 上部バーの言語メニューの隣に「インターフェース」メニュー（クラシック／イラスト）を追加。このブラウザに保存されます。既定はクラシックで、従来と同じです。
- デバイス設定 → 概要：ボードのベクター図（PCB ファイルの実際の位置、ライト／ダークテーマに追従）と、その両側にクリックできる値（バッテリー、読み取りモード、スキャン FPS とマトリクス、接続、ファームウェア、ライト）。クリックすると該当する設定セクションへ移動します。スキャンとピンは「マトリクス」1 つにまとめ、引き出し線が 2 つの FPC に分岐します。
- 電源と接続の経路：USB-C／バッテリー → 充電 → システム、デバイス → 中継 → サーバー。使用中の経路を実線で表示します。
- IO Visualizer：2 つの FPC の拡大図。ピンごとに四角で示し、有効なピンが点灯します。
- 読み取りモード、スキャンのプリセット、更新チャネルは大きな選択ボタン（選択中はチェック）に。送信はこれまでどおり「適用」を押したときです。
- GCU LTS ボードには図がなく、従来のカードのままです。

## その他

- v1.5.F / v2.0.F のデジタル FPC のピン表示を修正：接点 18 = GND、17 = SCL（GPIO 42）、16 = SDA（GPIO 40）、15 = NC（以前は位置がずれていました）。
- 充電中のバッテリーアイコンは、稲妻を電池の中に描き、くり抜きの縁取りで目立つようにしました。
- IO Visualizer のボード図は 460 px までに。Vref パネルに v2.0.F 裏面の Rfb0–13 の位置と、どれがはんだ付けされているか（rfb_measure の結果）を表示します。

Companion firmware release: **New Horizons OS v2.3.1**.
