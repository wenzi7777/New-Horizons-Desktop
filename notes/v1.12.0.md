# v1.12.0

**支援 New Horizons OS v2.1.0：App 改用 TypeScript 風格的語言撰寫，安裝時列出危險權限並要求同意。**

## App Studio

- 原始碼改為 `app.ts`，寫法是 TypeScript 的子集（`let/const`、函式、`if`/`while`/`for`、`Float32Array`、`on("frame", …)` 事件）；舊的 `.nhs` 語法不再支援。編輯器改用 TypeScript 語法標示與自動完成，錯誤直接標在行列上。
- 參考面板改由 SDK 的 `nhos.d.ts` 產生，列出每個 API 的簽名與說明，需要操作者同意的 API 會標示出來。
- 新範本、AI 提示與 README 都改為新語言；建置面板顯示記憶體用量（記憶池位元組）、App 的狀態變數，以及需要同意的權限。有迴圈的 App 不顯示每幀成本估計。
- 模擬器直接執行 bytecode：熱圖區域與觸發事件的程式行標示照常運作。

## 安裝

- App 宣告危險權限（儲存、裝置設定、串流、外接 I2C / UART）時，安裝對話框會列出說明，勾選同意後才能安裝，並以 `grant` 送給裝置。
- 板子沒有 App 需要的外接 I/O（I2C / UART 只在 v1.5.F、v2.0.F）時，安裝前就會提示，不會開始寫入。
- 新增錯誤訊息 `capability_not_granted`、`capability_unsupported`；App 套件改以 `vm` 驗證（不再需要 `nodes`）。

## 設備檔案

- 新增「App 資料」範圍，可瀏覽、下載 App 以 `store.append` 寫出的 CSV。

Companion firmware release: **New Horizons OS v2.1.0**（App Library 3.0.0）。
