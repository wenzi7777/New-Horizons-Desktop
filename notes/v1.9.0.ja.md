# v1.9.0

**旧 NH Gateway の受け付けを終了し、サーバーの FindMe 応答を新形式に。NH Studio / Pocket / headless 間のデバイス引き継ぎに対応します。**

## 中継

- 旧 Python NH Gateway はサーバーに接続できなくなりました。接続すると「NH Studio（または NH Studio headless）をお使いください」と返して切断し、Relays ページにも表示されません。
- Relays ページの「引き受ける」が NH Studio / NH Pocket でも機能します（以前はデバイスが移っても応答がなく、claim がタイムアウトしていました）。

## FindMe

- サーバーが直接デバイスに応答する offer を第 2 版にし、直接接続中のデバイス数を付けました。新しいファームウェアは負荷の軽い中継を選ぶのに使います。

Companion firmware release: **New Horizons OS v1.23.0**.
