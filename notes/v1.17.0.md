# v1.17.0

**視覺化卡片新增「轉置」（交換 X / Y 軸）；Gyro / Acc 改成圖形，並新增磁力計。**

## 轉置

- Row Mirror / Col Mirror 旁新增「轉置」勾選：行列互換（6 × 8 顯示成 8 × 6），尺寸標示、2D 熱圖、3D 曲面與 COP 一起跟著換。
- 先轉置、再鏡像：Row / Col Mirror 永遠翻轉畫面上看到的上下 / 左右；三個勾選組合出全部 8 種方向（轉置 + Col Mirror = 順時針轉 90°）。
- 只影響顯示：錄製與 CSV 不變；P 編號跟著感測器走，A.. / D.. 腳位標示在轉置時互換。勾選狀態記在這台瀏覽器。
- 選了感測器配置 profile 時無法轉置（profile 自己決定感測器位置）。

## IMU 與磁力計

- 數值列的 Gyro / Acc 換成三個面板，每個都是儀表 + 最近 10 秒 X / Y / Z 走勢線（紅 / 綠 / 藍，自動刻度）+ 同色數值：
  - 加速度計：水平儀（氣泡往高的一側）、|a| 與 roll / pitch。
  - 陀螺儀：X / Y / Z 置中橫條，刻度在 30–2000 °/s 間自動切換。
  - 磁力計（新）：指南針顯示板子 +X 的航向（以加速度計做傾斜補償）、µT 數值與 |B|。航向為原始值，不是精確羅盤。沒有磁力計的設備會顯示提示。
