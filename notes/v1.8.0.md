# v1.8.0

**Relays 頁不再累積舊的中繼、App token 與同步的安全與正確性修正，以及重新設計的 Vref 面板。**

## Relays

- 離線超過 7 天的中繼會自動從列表移除（環境變數 `NEWHORIZONS_RELAY_OFFLINE_TTL_DAYS` 可調，0 為保留）。重新安裝 NH Pocket、在新電腦安裝 NH Studio、Hub 恢復原廠設定都會產生新的中繼 ID，以前舊的 ID 會一直留著。
- 新增「移除離線」按鈕，一次移除所有目前離線的中繼；重新上線的會自動再登記。
- 刪除仍在線的中繼時，不會再留下一個永遠顯示「在線」、但送指令沒有反應的條目。
- 一條連線送來的狀態只會更新它自己的中繼。沒有 App token 的連線不能使用已登入 App 的中繼 ID，也不能冒充「已驗證」。

## App token

- 撤銷 App token 時，會立刻中斷它已開啟的連線（以前要等它自己重連）。
- 用帳號登入取得的 token，權限不會高於該帳號；帳號停用後 token 立即失效。
- App 登入連續輸錯密碼會暫時被拒絕；撤銷超過 30 天的 token 會從清單刪除。

## 同步（NH Studio / Pocket）

- Profile 與設備標籤改以伺服器收到的時間判斷「之後有沒有變更」：離線時修改、晚一點才上傳的內容，其他 App 也收得到。
- 一批資料中有任何一筆錯誤時，整批都不套用；狀態檔改用不會寫壞的方式儲存。
- 錄製上傳：每筆錄製各自鎖定，一筆在驗證大檔時不會卡住其他上傳；未完成超過 7 天的上傳會清掉；不帶大小的上傳不會被整包讀進記憶體。

## Vref 面板（v2.0.F）

- 上方三張狀態卡：目前 Vref 與所在區間（安全、已調高、接近開機風險、開機風險）、Rfb 與已量測行數、飽和行數與校準開關。
- 量程模式改為分段切換，點選即套用並附說明；尚未量測 Rfb 時直接提供「量測 Rfb」。
- Vref 改用滑桿，下方以綠、黃、紅標出安全、700–800 mV、800 mV 以上；自動模式下由設備調整。
- Rfb 量測與表格、校準開關、上限、Vref 掃描收在「工具」中。
- 切換設備不會帶著上一台的資料；欄位留空不會送出 0；清除 Rfb 後虛擬與自動模式會鎖住；掃描的等待時間與後端一致；預設上限 700 mV。
- 新的 Rfb 行狀態「ADC 讀取失敗」。
