# v0.13.0

搭配韌體 v1.6.0 的 **App 擴充**：App Studio 支援 IMU、磁力計、計時、百分比區域、背景執行與保存計數器；
readout 新增**圖表**；壓力台的**氣壓範圍改成正確接線後的數值**。

## App Studio 與 SDK

- SDK 同步到 App Library `a1f460d`（v1.6.0 op set）。
  - 新語法：event 名稱可當值用、`select`、`not`、布林條件、`emit … on fall(…)`、`signal … persist`、
    `background yes`、`region … rows 50%..100%`、負數門檻。
  - 新函式：`duration`、`interval`、`peak_since`、`counter(x, reset)`、`sqrt`、`atan2`、
    區域版 `peak`/`active`/`row_centroid`/`col_centroid`、`imu`、`mag`、`battery`、`linked`、`uptime`。
  - 編輯器的自動完成與函式說明補齊，`imu(`/`mag(` 會列出欄位。
- **模擬器帶入 IMU 與磁力計**：即時裝置的樣本與錄製檔的 `Acc_*`/`Gyro_*`/`Mag_*` 欄位都會餵給
  `imu()`/`mag()`。模擬時 `linked()` 視為已連線（frame 都是串流來的）。
- 所選板子沒有磁力計（v1.0.F）或電量計（v1.5.F 以外）時，會提示 app 用到的部分讀不到。

## Readout

- 新增 **`chart` 區塊**：最多 4 條數值曲線，保留最近 N 次輪詢（10–600，預設 60），
  缺值畫成斷點而不是 0。歷史只存在瀏覽器，開啟時從空白開始。
- 允許輪詢新的唯讀指令 **`sensor_sample`**（IMU、磁力計、電量）；`path` 指向物件時視為單列資料。
- App Library 新增的 **Sensor Scope** readout 用這兩者即時畫出加速度、角速度與磁場。

## 裝置與終端機

- 終端機新增 `sensor-sample` 指令；後端指令白名單與各模式閘門同步加入。
- 後端 App 庫驗證接受新的 op、能力（`tick`、`power`、`link`、`read_mag`、`persist`）與 `chart` 區塊，
  否則 Studio 編出的 v1.6.0 app 會在安裝時被拒。

## 壓力台氣壓範圍

MPX 感測器的 Vs 原本接在 Vin（讀數 ×2.19、零點 3.426），舊常數都是那時的讀數。依實驗結果改為：

- **上限 45 → 28 kPa**（腔體熱熔膠密封約 30 kPa 會漏，28 kPa 保壓 5 分鐘無漂移）；後端 `/api/pressure-cal/target`
  同步以 28 kPa 拒絕。
- **基準 3.5 → 0.5 kPa**（通大氣讀數約 0.384）。
- **殘壓安全測試 10 → 5 kPa**。
- 維護頁的預設點組重新配置在 28 kPa 以內，`experiment` 組改用論文主數據的點（2–20 kPa）。
