# v1.15.0

**Relays ページはオンラインの中継だけをカードで表示し、オフラインのものは「非アクティブな中継」一覧にまとめました。サインインしていないオフラインの中継は 1 日で自動削除されます。**

## Relays ページ

- NH Studio / NH Pocket / NH Studio headless、NH Hub、旧版 Gateway のいずれも、カードはオンラインの中継だけに表示します。サインイン済みのものが先頭です。
- オフラインの中継はすべて、ページ下部の「非アクティブな中継 (n)」ボタンにまとめました。開くとコンパクトな表（名前、ID、バージョン、サインイン状態、最終検出、削除）が表示されます。「オフラインを削除」ボタンもここに移りました。開閉状態はこのブラウザーに保存されます。
- セクション見出し「NH Studio / NH Pocket / NH Studio headless」を「アプリの中継」に変更し、オンライン台数を横に表示します。
- カードでは 0 の「拒否デバイス／UDP 転送／UDP 破棄」を表示しません。上流アドレスは production 以外（local、手動）に設定された中継だけに表示します。

## オフライン中継の自動削除

- 一度もサインインしていない NH Studio / NH Pocket / headless は、オフラインが 1 日続くと自動で削除されます（新規インストールや開発実行のたびに新しい中継 ID ができるため、一覧が長くなる主な原因でした）。サインイン済みの中継、NH Hub、旧版 Gateway は従来どおり 7 日です。
- `NEWHORIZONS_UNAUTH_RELAY_OFFLINE_TTL_DAYS` で変更できます。0 にすると他の中継と同じ（7 日）になります。

Companion firmware release: **New Horizons OS v2.3.1**.
