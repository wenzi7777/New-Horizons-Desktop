# v0.15.1

**板子型號再改名：TIA-CTL/R → TIA-CTL。**

## 為什麼

名稱裡的「/R」原本指跨阻級的回授電阻 Rfb。電路上 Rfb 仍然存在，但名稱不再標示它，所以型號改成 TIA-CTL。TIA 是 TransImpedance Amplifier（跨阻放大器）。

## 變更

- **畫面上的型號一律顯示 TIA-CTL**：Launchpad、Visualization、Device Settings、Terminal 的 I/O 設定視窗。
  - 還在跑舊韌體的裝置也會顯示成 TIA-CTL：v1.8.0 以前回報 `VD-CTL/R …`，v1.8.0 回報 `TIA-CTL/R …`。
- **Wiki**：各板子頁面的標題與內文改成 TIA-CTL。網址（`vd-ctl-r-*`）不變。
- **三種名稱都認得**：從 New Horizons OS v1.8.1 起，韌體回報 `TIA-CTL …`。前端和後端比對型號時，把開頭的 VD-CTL/R 和 TIA-CTL/R 都視為 TIA-CTL，板子設定和 wiki 都對得到同一塊板子。

## 驗證

- Python（483）、frontend（91）測試全數通過，舊名稱測試改成涵蓋 VD-CTL/R 與 TIA-CTL/R；`npm run build` 通過。
- **尚未在瀏覽器與實機上驗證**：接上跑 v1.7.5、v1.8.0、v1.8.1 的裝置，都應顯示 `TIA-CTL …`，板子設定也應正確。

## 相容性

- 應先於韌體 v1.8.1 更新 Desktop。v0.15.0 以前的 Desktop 認不出 `TIA-CTL …`，會退回 v1.0.F 的預設設定。
- 不改變任何指令或資料格式。

Companion firmware release: **New Horizons OS v1.8.1**.
