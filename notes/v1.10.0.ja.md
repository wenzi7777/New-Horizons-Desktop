# v1.10.0

**NH Studio / NH Pocket はアカウントで自動サインインするようになり、Relays ページの App token 管理はなくなりました。カードのボタンがはみ出さなくなりました。**

## サインイン

- Relays ページの「サインイン中のアプリ（App token）」を削除しました。NH Studio / NH Pocket はサインインしたアカウントを記憶し、起動するたびに自動でサインインし直すため、トークンを手動で無効化・管理する必要はありません。
- Relays ページの NH Studio / NH Pocket のカードには「サインイン済み：アカウント」または「未サインイン」を表示します。NH Studio headless と NH Hub はサインイン不要のため表示しません。
- 同じアプリがサインインし直すと以前のトークンは無効になり、30 日間使われていないトークンも自動で無効になります。トークンが溜まり続けることはありません。

## 修正

- Relays ページのカードが狭いとき、「管理」「削除」ボタンは次の行に折り返し、カードからはみ出さなくなりました。

Companion firmware release: **New Horizons OS v1.23.0**.
