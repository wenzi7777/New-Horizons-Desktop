# v1.0.3

**登入頁和關於視窗的實驗室、大學名稱加上網站連結。首頁的資料夾改用跟其他視窗相同的遮罩打開。**

## 實驗室與大學連結

- **登入頁底部**：實驗室與大學名稱改成同一行，用「·」隔開，兩者都可以點。
- **關於視窗**：實驗室名稱和會津大學 logo 也都可以點。
- 連結都在新分頁開啟：
  - Human Intelligent Sensing Lab：https://isensing.u-aizu.ac.jp/
  - 會津大學：https://u-aizu.ac.jp/

## 首頁資料夾

- 點資料夾卡片只會打開資料夾。卡片裡的設備名稱只是預覽，不能點，滑鼠移上去也不會變色。
- 打開後的視窗改用跟其他視窗一樣的遮罩：背景變暗、模糊，視窗有淡入動畫。點視窗外面或按 Esc 可以關閉。

Companion firmware release: **New Horizons OS v1.17.0**.
