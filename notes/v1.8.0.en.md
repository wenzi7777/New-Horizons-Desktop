# v1.8.0

**The Relays page no longer piles up old relays, app token and sync fixes for safety and correctness, and a redesigned Vref panel.**

## Relays

- Relays offline for more than 7 days leave the list by themselves (`NEWHORIZONS_RELAY_OFFLINE_TTL_DAYS`, 0 keeps them). Reinstalling NH Pocket, installing NH Studio on a new computer or resetting a Hub each makes a new relay id, and the old ids used to stay forever.
- A "Remove offline" button removes every relay that is offline now; any that come back online register again.
- Deleting a relay that is online no longer leaves an entry that shows "online" forever but never answers a command.
- A connection's status only updates its own relay. A connection without an app token can't use the id of a signed-in app or pass itself off as authenticated.

## App tokens

- Revoking an app token also closes the connections it has open.
- A token from signing in never outranks its account and stops working as soon as the account is deactivated.
- Repeated wrong passwords at app sign-in are refused for a while; tokens revoked more than 30 days ago are removed from the list.

## Sync (NH Studio / Pocket)

- Profiles and device labels decide "changed since" by when the server received a change, so an edit made offline and sent later still reaches the other apps.
- A batch with any bad item applies nothing; the state files are written so a crash can't leave them broken.
- Recording upload: each recording has its own lock, so checking a large file doesn't hold up other uploads; uploads left unfinished for 7 days are removed; an upload without a size is no longer read into memory whole.

## Vref panel (v2.0.F)

- Three status tiles on top: the current Vref and its zone (safe, raised, close to the boot risk, boot risk), Rfb with the rows measured, and rows at the rail with the calibration switch.
- The range mode is a segmented control that applies when chosen, with a line explaining it; without a measured Rfb, "Measure Rfb" is right there.
- Vref is a slider with a bar marking safe, 700–800 mV and above 800 mV in green, yellow and red; in auto mode the device sets it.
- Measuring Rfb and its table, the calibration switch, the ceiling and the Vref sweep are under "Tools".
- Switching devices no longer carries over the last one's data, an empty field no longer sends 0, clearing Rfb locks the virtual and auto modes, the sweep waits as long as the backend, and the default ceiling is 700 mV.
- A new Rfb row status, "ADC read failed".
