# v0.14.1

搭配韌體 v1.7.2：**背景輪詢不再讓狀態 LED 一直閃**；**App 的介紹有日文與中文版**。

## 背景指令不閃燈

- 程式自己發出的指令都帶 `"quiet": true`，韌體 v1.7.2 起不再為它們做 LED 確認閃爍：
  - App 頁籤的即時預覽（`app_view`）；
  - Readout 的定時輪詢；
  - 設定頁的自動刷新：電量同步時每秒一次的 `status`、RAM 監控的 `memory_status`，以及開啟頁籤時自動讀取的 `status`；
  - 後端錄製時輪詢的 `app_events`，以及時鐘未同步時自動推送的 `set_time`。
- 使用者手動按的按鈕和終端機指令都不帶，照常閃燈確認。
- 這個欄位統一由 `quietCommand()` 加上，靜態測試會鎖住手動操作的路徑不帶它。

## App 介紹 i18n

- App Library 的 20 個 app 都新增日文與簡中 README，App 商店的詳細介紹會依介面語言顯示，沒有對應語言時退回英文。
- 裝置 Apps 清單、slot 卡片和 Readout 標題中的套件名稱與簡介，改用 App Library 目錄中對應語言的文字。
  離線或是側載、目錄中沒有的套件，仍顯示裝置回報的原文。

## 驗證

- Python（479）、frontend（85）測試全數通過；`npm run build` 通過。
- **尚未在瀏覽器與實機上驗證**：開著即時預覽或 Readout 時 LED 不再持續閃爍，以及日文和中文介面下的 app 名稱與介紹。
