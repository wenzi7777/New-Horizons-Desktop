# v0.29.0

**新增「關於」視窗：點左上角的 Console 與版本號即可開啟，顯示 Human Intelligent Sensing Lab、會津大學，以及各版本的更新日誌。登入頁底部也加上了實驗室與大學的署名。**

## 關於視窗

- **入口**：左上角的「Console」與版本號現在是一顆有邊框的按鈕，右側有 ⓘ 圖示，滑鼠移上去會變綠。不另外佔用頁籤。
- **內容**：
  - New Horizons OS 與目前的版本號。
  - Human Intelligent Sensing Lab（襯線斜體字）。
  - 會津大學的標誌與校名，校名會隨介面語言切換（日文、簡中顯示「会津大学」）。
- **更新日誌**：視窗下半部可以選擇版本，預設為目前的版本，並標註「當前」。內容就是每次發布時寫的版本說明，所有舊版本都能查看。
- 按 Esc、點視窗外面或按「關閉」都可以關閉。

## 登入頁

- 頁面底部加上一行小字：`Human Intelligent Sensing Lab · The University of Aizu`，校名會隨語言切換。

## 其他

- 版本說明裡縮排的子項目，以前會和上一層顯示在同一層，現在會往內縮一層。App Store 的 README 也套用同樣的顯示方式。
- 字型檔已一起打包進前端，離線使用也能正常顯示。
