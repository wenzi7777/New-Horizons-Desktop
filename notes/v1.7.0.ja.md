# v1.7.0

**TIA-CTL v2.0.F の Vref とレンジの操作パネル:Vref 設定、校正スイッチ、Rfb 測定、レンジモード、Vref スイープ。**

## Vref と校正スイッチ

- デバイス設定ページの Vref カードに追加:Vref の入力、330 mV に戻す、上限の設定、校正スイッチの切り替えボタン。
- 約 800 mV を超えると再起動時に起動失敗の恐れがあり、画面で注意します。Vref は再起動のたびに 330 mV へ戻ります。

## Rfb

- 「Rfb を測定」ボタン:各行の Rfb、ADC オフセット、状態(正常、Rfb 未実装、この Vref では大きすぎる、校正回路に何もつながっていない)。測定時の Vref は別に指定できます。

## レンジ

- レンジモード:Raw(そのまま)、Virtual Rfb(基準 Rfb・330 mV で読んだ値に換算。20k 基板で作った校正がそのまま使えます)、Auto(Virtual に加え、行がレールに達する間 Vref を下げる)。基準 Rfb と GPIO45 の漏れ補正を設定できます。
- Virtual と Auto には先に Rfb の測定が必要です。直近フレームでレールに達した行数も表示します。

## Vref スイープ

- 圧力を一定に保ったまま Vref を段階的に変え、各 Vref の Rfb、Rs の中央値、レールに達したセル数を表に示し、スイープ中の Rs の変動幅を表示します(純抵抗なら 0 に近くなります)。完全な CSV をダウンロードできます。
