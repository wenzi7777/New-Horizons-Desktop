# v1.6.0

**新基板 TIA-CTL v2.0.F を認識し、ID 抵抗で識別したバッテリーを表示し、Vref カードを追加しました。**

## TIA-CTL v2.0.F

- v2.0.F を追加:マトリクスとピンは v1.5.F と同じ(14 × 14)、ファームウェア更新は `arduino-v20f` トラック、Wiki ページ付き。
- SDK の仮想デバイスに v2.0.F が加わりました。

## バッテリー

- ファームウェアが ID 抵抗でバッテリーを識別した場合、バッテリーカードにその旨と容量・充電電流を表示し、手動設定フォームを隠します。詳細にはバッテリー ID の行が加わります。
- ID 抵抗がない場合(JST バッテリー)や未知の抵抗値では、従来どおり手動設定です。

## Vref

- デバイス設定ページに読み取り専用の Vref カードを追加:現在値、上限、電源投入時の値(DAC の EEPROM)、校正スイッチの状態。

Companion firmware release: **New Horizons OS v1.21.0**.
