# v0.17.0

**電池改成手動設定；Mode 卡片可以直接退出維護模式；新增「重啟並進入配網」按鈕。**

## 電池設定（Device Settings → 硬體）

- **移除「Detect battery ID」按鈕**，後端也不再接受 `detect_battery_profile`。目前的 PCB 無法可靠辨識電池，下一版 PCB 才會加回自動偵測。
- **電池設定改成隨時可以修改**。
  - 以前只有在「需要設定」時才會出現；現在有電量計的板子（v1.5.F）會一直顯示「電池」設定區塊，可以填容量和最大充電電流。
  - 表單會自動帶入設備目前存的值。
- 還沒設定電池時，會提示「充電限制為 100 mA，直到你存好設定」。
- 移除「Profile source / Profile resolved / Profile required」三個欄位。容量沒設定時顯示「未設定」。
- 搭配韌體 v1.10.0，充電檔位不會超過電池的最大充電電流。

## 退出維護模式

- 設備處於維護模式或安全維護模式時，頁面頂端的 **Mode 卡片**會出現「退出維護模式」按鈕。
- 按下後設備直接回到一般模式並恢復掃描，不需要重開機。

## 重啟並進入配網

- **Overview 的 Reboot 旁邊新增「重啟並進入配網」按鈕**，給按鈕壞掉的板子使用。
  - 按下會先跳出確認視窗，接著設備重開機並開啟 Wi-Fi 設定熱點，效果和開機時按住按鈕相同。
  - 設備會和本應用斷線，連上它的熱點完成設定後才會回來。
- 終端機新增 `reboot-wifi-setup` 指令。
- 需要韌體 v1.10.0；舊韌體會回 `unknown_command`。

## 驗證

- Python（483）、frontend（91）測試全數通過；`npm run build` 通過。
- **尚未在瀏覽器與實機上驗證**。

## 相容性

- 接上舊韌體時，電池設定區塊照常可用；「重啟並進入配網」會回 `unknown_command`。
