# v1.2.0

**Gateway 可以在 Relays 頁面管理了，跟 Hub 一樣。**

## Gateway 管理

- Gateway 卡片多了「管理」按鈕，需要更新時卡片上會顯示提示。
- 管理視窗分成幾區：
  - 總覽：版本、通道、連線目標、服務中的裝置
  - 連線：Gateway ID、目標（production / local / manual）、manual URL；Gateway 需要更新時鎖定
  - 更新：檢查更新、立即更新、切換 stable / beta 通道、更新日誌
  - LAN 裝置：服務中、附近、已拒絕的裝置；探索、允許、拒絕、接管
  - 維護：重新啟動、恢復預設設定、刪除
- 不能從 Desktop 停用 Gateway：停用後就連不到它了。
- 恢復預設會讓 Gateway 離線，需要回到 Gateway 本機 WebUI 重新設定，確認框會先提醒。
- 舊版 Gateway（v0.7.x 以前）只顯示總覽，並提示先在 Gateway 本機 WebUI 更新到 v1.0.0。

## Hub 管理

- Hub 與 Gateway 的更新區塊改用同一份元件，Hub 的行為不變。

## Backend

- Hub 與 Gateway 各自只接受自己的管理指令；不支援遠端管理的舊版 Gateway 會直接回 `unsupported_by_relay`，不再等到逾時。
- 記錄 Gateway 回報的更新通道、更新狀態與附近裝置。

## 相容性

- 搭配 Gateway v1.0.0（同日發布）。Gateway v1.0.0 起，需要更新時會在閒置 60 秒後自動更新。
- 舊版 Gateway 照常運作，只是不能遠端管理。

Companion firmware release: **New Horizons OS v1.17.1** / **New Horizons Hub v0.12.0** / **New Horizons Gateway v1.0.0**.
