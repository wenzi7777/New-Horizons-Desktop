# v1.2.4

**Release notes are shown in Japanese or English to match the UI language.**

## Release notes

- In the About dialog, the device update card and the Hub/Gateway update cards, release notes appear in Japanese for the Japanese UI and in English for the English UI; versions without a translation fall back to the Traditional Chinese original. The Simplified Chinese UI shows the Traditional Chinese original.
- Translations sit beside the original (`vX.Y.Z.ja.md`, `vX.Y.Z.en.md`), so manifests are unchanged and older firmware, Hubs and Gateways need no update.
- After changing the UI language, opening an update card's release notes again loads the new language (the device update card collapses them automatically).
- From this version on every release ships Japanese and English; older releases have only the Traditional Chinese original.

Companion firmware release: **New Horizons OS v1.18.0**.
