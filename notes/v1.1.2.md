# v1.1.2

**同一個 LAN 有兩台 Gateway 時，設定頁的設備 Gateway 不再在兩台之間來回跳動。**

## Gateway 歸屬

- 設備會回覆任何一台 Gateway 送來的指令，但串流和 heartbeat 只送給 FindMe 選中的那一台。以前後端只要收到某台 Gateway 轉發的指令回覆，就把那台登記成設備的 Gateway，下一個指令也改走它。
- 設定頁定期拉 `status` 時，這會讓兩台 Gateway 輪流成為設備的 Gateway：每次回覆都把歸屬改到轉發的那台，另一台的 heartbeat 快照又把它改回來。
- 現在，如果已經有別台 Gateway 正在服務這台設備，經由另一台 Gateway 轉發的回覆仍會照常顯示結果，但不會改變設備的 Gateway，也不會改變之後指令走的路徑。歸屬只由 Gateway 回報的連線狀態決定。

## 相容性

- 搭配 Gateway v0.7.1（Gateway 也不再因為指令回覆就宣稱接管設備）。只更新其中一邊，來回切換也會停止。
- 設備韌體不用改。

Companion firmware release: **New Horizons OS v1.17.0** / **New Horizons Gateway v0.7.1**.
