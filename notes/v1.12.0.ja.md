# v1.12.0

**New Horizons OS v2.1.0 に対応：アプリは TypeScript 風の言語で書くようになり、インストール時に危険な権限を表示して同意を求めます。**

## デバイスのアプリ

- デバイスのアプリは設定（設定 → アプリ）に移りました。独立したデバイスアプリのページは廃止しました（古いリンクは転送されます）。
- スマートフォンのバックグラウンドアプリ画面のような構成です：実行中のアプリごとに色分けしたメモリと CPU のバー、あと何個入るか。実行中のアプリはカードで、OLED / LED に表示中の内容、負荷（1 分間の推移グラフ付き）、メモリと CPU を表示。その他のアプリはスイッチ付きの行で、入らない場合は理由を先に表示します。
- アプリをタップすると詳細：1 / 10 / 60 秒の負荷、借りている時間、権限、そのアプリだけの最近のイベント、一時停止 / 再開、復帰、先頭へ（共有の表示行を優先）、App Store、アンインストール。
- スロットとメンテナンスのスイッチはなくなりました：アプリのオン／オフ時に自動でメンテナンスモードに入り、終われば戻ります（スキャンは約 1 秒止まります）。記録中は先に確認します。
- ターミナル：`app-reorder` を追加。`app-enable`、`app-disable`、`app-load-flow`、`app-unload-flow` を削除（ファームウェア v2.1.0 にはありません）。

## App Studio

- ソースは `app.ts` になり、TypeScript のサブセット（`let/const`、関数、`if`/`while`/`for`、`Float32Array`、`on("frame", …)` イベント）で書きます。旧 `.nhs` 構文はサポートしません。エディターは TypeScript のハイライトと補完を使い、エラーは行と列に表示されます。
- リファレンスパネルは SDK の `nhos.d.ts` から生成され、各 API のシグネチャと説明を表示し、オペレーターの同意が必要な API に印を付けます。
- 新しいテンプレート、AI プロンプト、README を新言語に対応。ビルドパネルはメモリ使用量（プールのバイト数）、アプリの状態変数、同意が必要な権限を表示します。ループを含むアプリにはフレームあたりのコスト見積もりを表示しません。
- エミュレーターはバイトコードを直接実行します。ヒートマップの領域とイベントを発生させた行の表示はこれまでどおり動作します。

## インストール

- アプリが危険な権限（ストレージ、デバイス設定、ストリーミング、外部 I2C / UART）を宣言している場合、インストールダイアログで説明を表示し、同意にチェックを入れた後でのみインストールし、`grant` としてデバイスに送ります。
- アプリに必要な外部 I/O がボードにない場合（I2C / UART は v1.5.F と v2.0.F のみ）、書き込みを始める前に表示します。
- エラーメッセージ `capability_not_granted`、`capability_unsupported` を追加。アプリパッケージは `vm` で検証します（`nodes` は不要になりました）。

## デバイスのファイル

- 「アプリのデータ」スコープを追加し、アプリが `store.append` で書いた CSV を閲覧・ダウンロードできます。

Companion firmware release: **New Horizons OS v2.1.0**（App Library 3.0.0）。
