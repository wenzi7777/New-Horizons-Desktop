# v1.9.0

**The old NH Gateway is retired, and the server's FindMe answers use the new format, for devices that NH Studio, Pocket and headless take over from each other.**

## Relays

- The old Python NH Gateway can no longer connect: it is told to use NH Studio (or NH Studio headless) instead and disconnected, and it never appears on the Relays page.
- "Take over" on the Relays page now works for NH Studio and NH Pocket too (before, the device moved but got no answer and the claim timed out).

## FindMe

- The server's own offers are version 2 and carry how many devices stream to it directly; current firmware uses that to pick the less loaded relay.

Companion firmware release: **New Horizons OS v1.23.0**.
