# v1.6.0

**認得新板 TIA-CTL v2.0.F，電池卡片顯示由 ID 電阻辨識的電池，並新增 Vref 資訊卡。**

## TIA-CTL v2.0.F

- 新增 v2.0.F 板型：矩陣與腳位同 v1.5.F（14 × 14），韌體更新走 `arduino-v20f` 軌道，附 Wiki 頁面。
- SDK 的虛擬設備新增 v2.0.F 板型。

## 電池

- 韌體辨識出電池的 ID 電阻時，電池卡片會標示「已由 ID 電阻辨識」並顯示容量與充電電流，同時隱藏手動設定表單；詳細資訊多一列電池 ID。
- 沒有 ID 電阻（JST 電池）或不認得的阻值，仍然使用手動設定。

## Vref

- 設備設定頁新增唯讀的 Vref 資訊卡：目前值、上限、開機預設值（DAC 的 EEPROM）與校準開關狀態。

Companion firmware release: **New Horizons OS v1.21.0**.
