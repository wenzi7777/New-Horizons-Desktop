# v0.21.0

## 裝置設定頁

- **頂部 Mode 卡片改成下拉框**：預設選在目前的模式（一般／維護）。選了不同的模式才會出現「套用」，套用後進入或退出維護模式。取代原本只在維護模式時出現的「退出」按鈕。處於安全維護模式時會顯示現況，但不能選它。
- **時鐘**：加上大字的數位時鐘，顯示裝置目前的時間（到 0.1 秒，每 0.1 秒更新），旁邊並列這台電腦的時間方便對照。數值含回應的傳輸延遲，只供目視比對。
- **健康卡片**：經 Hub 連線的裝置會顯示 ESP-NOW 連線品質：與 Hub 斷線次數、放棄的回覆、ESP-NOW 送出失敗。需要韌體 v1.13.0。
- **版面修正**：
  - 外接 LED 卡的 Mode 下拉框不再被同一列的說明文字撐高。
  - 掃描效能卡的 FPS 預設按鈕不再被拉得跟右側表單一樣高，文字也垂直置中。

## App Store 安裝

在 App 詳情頁按「安裝到裝置…」，在同一個對話框內完成：

1. **選裝置**：每張卡片顯示名稱或暱稱、UID、板子、線上狀態、模式、韌體版本。預設只列線上而且相容的裝置；勾選「顯示無法安裝的裝置」才會列出其他裝置，並註明原因（離線、韌體太舊）。
2. **確認**：說明安裝期間會暫停掃描。
3. **安裝**：逐步顯示進度：進入維護模式 → 上傳（百分比）→ 安裝 → 回到一般模式。
   - 原本就在維護模式的裝置不會被切回一般模式。
   - 失敗或取消時，只要是這次切進維護模式的，也會切回去。

裝置 Apps 頁的舊連結（`?install=`）會打開同一個對話框，並直接選好該裝置。

## App Studio

- 「AI prompt」改名為「Generate code」（コードを生成／生成代码）。
- **作者**：
  - 第一次進入 Studio 會要求填寫作者名稱，只存在這台電腦。不再使用登入帳號，因為研究室帳號是共用的。
  - 工具列可以隨時修改作者名稱。
  - 第一次填寫時，作者仍是 admin 等自動填入值的 App 會一起更新。
- **詳細資料**：建置分頁頂部可以直接編輯名稱、作者、摘要，離開欄位時寫回程式碼。作者只能是一個詞，空白會轉成 `_`。

## Relays

- Hub 的「管理」改回在 Relays 頁上開彈出視窗，不再跳到新頁面。視窗內保留各分頁（概要、連線、時計、韌體更新、裝置、維護）。
