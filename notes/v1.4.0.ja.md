# v1.4.0

**NH Studio と NH Pocket のサーバー側対応。ソフトウェア Gateway は NH Studio に置き換わります。**

## Relays ページ

- 「Gateway」の欄は「NH Studio / NH Pocket」になり、接続の種類に応じて Studio、Pocket、Hub と表示します。
- 旧 Python Gateway も接続でき、「旧 Gateway」の欄に NH Studio への移行案内つきで表示されます。
- ダウンロードボタンは新しいダウンロードページ（New Horizons Studio / New Horizons Studio Pocket）に移りました。
- Studio / Pocket のカードには認証済みかどうかを表示します。

## Desktop のアカウントでサインイン

- NH Studio、NH Pocket、Studio headless 版は Desktop のユーザー名とパスワードでサインインします。パスワードは一度だけ確認され、サーバーはそのコンピューターやスマートフォン専用のトークン（アカウントと同じ権限）を発行します。セッションは作らず、パスワードも保存しません。
- トークンは Relays ページの「アプリトークン」に、どのアカウント・どの機器かとともに一覧され、管理者が取り消せます。サインアウト時はアプリ自身が取り消します。
- 管理者が Relays ページで直接トークンを作ることもできます。

## 同期

- 録画のアップロード：分割・再開に対応し、従来のフォルダー構成に保存され、Files ページに表示されます（送信元も記録）。
- デバイスのニックネーム、グループ、プロファイルを双方向に同期します（最後に更新したほうが優先）。
- サーバーの FindMe 応答が、Studio・Pocket・Gateway が管理中のデバイスを奪わなくなりました。

Companion firmware release: **New Horizons OS v1.19.1**.
