# v1.5.0

**NH Studio headless now has the Hub's standing; relays are named NH Studio / NH Pocket / NH Studio headless / NH Hub by connection type.**

## NH Studio headless

- A new connection type `relay`: like the Hub it needs no sign-in, only relays and records nothing. The Relays page lists it with NH Studio / NH Pocket as "NH Studio headless".
- The old Python Gateway still connects; it is listed under "Legacy Gateway" with a pointer to NH Studio.

## Names

- "Connected via NH Gateway" on device views now names the actual relay: NH Studio, NH Pocket, NH Studio headless or NH Hub.

## Relays page

- The "Create token" form is gone: apps sign in with a Desktop account. The list of signed-in apps and their revoke buttons remain.

## Relay performance test

- New `POST /api/relay-bench`: the "Relay performance" test of NH Studio / NH Pocket times its upload to the server with it (the body is read and discarded, up to 16 MB).

Companion firmware release: **New Horizons OS v1.20.0**.
