# v1.2.4

**リリースノートを UI の言語に合わせて日本語版または英語版で表示するようにしました。**

## リリースノート

- 「このアプリについて」ダイアログ、デバイスの更新カード、Hub/Gateway の更新カードのリリースノートは、日本語 UI では日本語版、英語 UI では英語版を表示します。翻訳がないバージョンは繁体字中国語の原文に戻ります。簡体字中国語の UI では繁体字中国語の原文を表示します。
- 翻訳ファイルは原文の隣に置きます(`vX.Y.Z.ja.md`、`vX.Y.Z.en.md`)。manifest は変わらず、旧ファームウェア、Hub、Gateway を更新する必要はありません。
- UI の言語を切り替えた後、更新カードのリリースノートを開き直すと新しい言語で表示されます(デバイスの更新カードは自動で閉じます)。
- このバージョンから、毎回のリリースに日本語版と英語版を付けます。旧リリースには繁体字中国語の原文しかありません。

Companion firmware release: **New Horizons OS v1.18.0**.
