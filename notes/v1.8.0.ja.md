# v1.8.0

**Relays ページに古い中継がたまらなくなり、App token と同期の安全性・正確さを修正し、Vref パネルを作り直しました。**

## Relays

- 7 日以上オフラインの中継は一覧から自動で消えます（環境変数 `NEWHORIZONS_RELAY_OFFLINE_TTL_DAYS` で調整、0 で保持）。NH Pocket の再インストール、新しいパソコンへの NH Studio のインストール、Hub の初期化はどれも新しい中継 ID を作り、以前は古い ID が残り続けていました。
- 「オフラインを削除」ボタンで、いまオフラインの中継をまとめて削除できます。再びオンラインになったものは自動で登録されます。
- オンラインの中継を削除しても、「オンライン」のまま指令に応答しない項目が残らなくなりました。
- 接続から届いた状態は、その接続自身の中継だけを更新します。App token のない接続は、サインイン済み App の中継 ID を使えず、「認証済み」を装うこともできません。

## App token

- App token を取り消すと、その token で開いている接続もすぐ切断します。
- アカウントでサインインして得た token は、そのアカウントより強い権限を持たず、アカウントを無効にするとすぐ使えなくなります。
- App のサインインでパスワードを続けて間違えると一時的に拒否されます。取り消して 30 日を過ぎた token は一覧から削除されます。

## 同期（NH Studio / Pocket）

- Profile とデバイスのラベルは、サーバーが受け取った時刻で「その後の変更」を判断するようにしました。オフラインで編集し、あとから送った内容もほかの App に届きます。
- 1 件でも不正なデータがあれば、そのまとまりは何も適用しません。状態ファイルは壊れない方法で保存します。
- 録画のアップロード：録画ごとにロックし、大きなファイルの検証中もほかのアップロードを止めません。7 日以上未完了のアップロードは削除し、サイズを示さないアップロードを丸ごとメモリに読み込まなくなりました。

## Vref パネル（v2.0.F）

- 上部に 3 つの状態カード：現在の Vref と区分（安全・引き上げ中・起動リスクに近い・起動リスク）、Rfb と測定済みの行数、飽和している行と校正スイッチ。
- 量程モードはセグメント切り替えで、選ぶとすぐ適用され説明が表示されます。Rfb 未測定のときは「Rfb を測定」をその場で押せます。
- Vref はスライダーになり、下の帯で安全・700–800 mV・800 mV 超を緑・黄・赤で示します。自動モードでは装置が調整します。
- Rfb 測定と表、校正スイッチ、上限、Vref スイープは「ツール」にまとめました。
- デバイスを切り替えても前のデータが残らず、空欄で 0 を送らず、Rfb を消去すると仮想・自動モードがロックされ、スイープの待ち時間がバックエンドと一致し、既定の上限は 700 mV になりました。
- Rfb の行の新しい状態「ADC の読み取りに失敗」。
