# v1.3.1

**Fix: every time the system monitor refreshed, the Run box lost focus so you could not type, and the "⋯" menus would not open.**

## Cause

- The system monitor's once-a-second poll went through the operator command path, so the page was marked busy every second. While busy, the input box and the "⋯" buttons were disabled: typing lost focus mid-word, and a "⋯" click that landed during a poll did nothing.
- On the device settings page those polls were also written to the operation log and refetched the device list every second.

## Fix

- Polls now use the background path: they never mark the page busy or write to the operation log. Fixed on both the device settings page and the Apps page.
- While an action is being sent, that poll is skipped; the screen keeps the previous data instead of blanking the tables, and the "Updated" time shows how old it is.
- The input box and the "⋯" buttons are no longer disabled while busy. While a command is in flight only the Run button, Enter and the menu's action items wait, so no typing or click is lost.

Companion firmware release: **New Horizons OS v1.19.0**.
