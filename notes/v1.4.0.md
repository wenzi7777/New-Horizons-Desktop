# v1.4.0

**NH Studio 與 NH Pocket：伺服器端支援。軟體 Gateway 由 NH Studio 取代。**

## Relays 頁

- 「Gateway」區塊改名為「NH Studio / NH Pocket」，依連線種類顯示 Studio、Pocket 或 Hub。
- 舊版 Python Gateway 仍可連線，顯示在「舊版 Gateway」區塊，並提示改用 NH Studio。
- 下載按鈕改連到新的下載頁（New Horizons Studio / New Horizons Studio Pocket）。
- 每張 Studio / Pocket 卡片會標示是否已驗證。

## 用 Desktop 帳號登入

- NH Studio、NH Pocket 與 Studio headless 版改用 Desktop 的帳號密碼登入。密碼只驗證一次，伺服器發一個給該台電腦或手機專用的 token，權限與帳號相同；不建立 session，也不保存密碼。
- 這些 token列在 Relays 頁的「App tokens」，看得到是哪個帳號、哪台裝置，管理員可以撤銷。登出時 App 會自己撤銷。
- 管理員也可以直接在 Relays 頁建立 token。

## 同步

- 錄製上傳：分塊、可續傳，存進原本的資料夾結構，Files 頁看得到，並記錄來源。
- 裝置暱稱、群組與 profile 雙向同步，以最後修改時間為準。
- 伺服器的 FindMe 回應不再搶走已由 Studio、Pocket 或 Gateway 管理的裝置。

Companion firmware release: **New Horizons OS v1.19.1**.
