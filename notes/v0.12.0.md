# v0.12.0

App Studio 的模擬器改成**先選設備**：可以直接用真實設備，也可以開一台**虛擬設備**，自選板型、矩陣大小與資料來源。另外支援韌體 v1.5.0 的**外置 LED 燈條**。

## 模擬器：真實設備與虛擬設備

- 編輯器工具列原本的「Board」下拉（只顯示 `8 × 8`、`15 × 15` 這類尺寸）改成唯讀的「目標設備」標籤，點下去會切到模擬器分頁。**Build 分頁的耗時判定與韌體版本檢查，一律以模擬器選的設備為準**。
- 設備清單會顯示型號與目前的矩陣大小，例如 `NHOS-3CDC… · v1.5.F · 2 × 2`；離線的設備會標出狀態。
- **真實設備**：可選「即時串流」或「這台的錄製檔」。
- **虛擬設備**：
  - **板型**：v1.0.F、v1.5.F、v2.1 / v2.2.C / v2.3.D GCU LTS。OLED、按鍵、外置 LED 數量依板型自動帶出，不需要自己設定。
  - **矩陣**：可以比板型小，但不能超過板型上限。
  - **資料來源「錄製檔」**：可選任何一台設備的錄製檔，或開啟本機 CSV。載入後矩陣自動改成錄製檔的尺寸；超過板型上限時會提示。
  - **資料來源「生成資料」**：以 60 fps 執行。可選的模式有：無（只用滑鼠）、每 2 秒輕按、長按 3 秒、橫向滑過、緩升到滿量程，另有背景噪音滑桿。**在熱圖上按住滑鼠就能施壓**，按越久壓力越大。
- App 用到板型沒有的 OLED、按鍵或外置 LED 時會提示，模擬器也不會模擬出不存在的硬體。
- 虛擬設備的設定與選擇的設備會記在瀏覽器裡。

## NHS 新語法：外置 LED

內建的 SDK 同步至 App Library `5476111`：

```
pixel <index> <colour> when <event>   # 事件成立的幀點亮第 index 顆
meter <expr> range <lo>..<hi>         # 依比例點亮燈條，綠到紅
```

- 用到這兩個語法的 App 會自動標示需要 `min_os: v1.5.0`。
- 模擬器會依板型預覽燈條：v1.0.F 3 顆、v1.5.F 9 顆。像素超出板子數量時會提示。
- 語法上色與「參考」分頁都已加入新語法。

## 裝置設定

外置 LED 的 preset 下方加上說明：**使用外置 LED 的 App 執行時，優先於 preset**，App 停止後恢復原本的 preset。App 正在控制時也會另外提示，「有效プリセット／活动预设」會顯示為「App（執行中）」。wiki 的 v1.0.F LED 頁面三種語言也已更新。

## 修正

- 後端的套件檢查補上 `drive_ext_led` capability 與 `ext_pixel`、`ext_meter` 兩個 op，否則這類 App 安裝時會被拒絕。
