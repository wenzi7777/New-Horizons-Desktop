# v0.23.0

**Desktop 改以裝置自己回報的指令表為準：韌體新增的指令不用更新 Desktop 就能使用。**

## 裝置指令表

- 韌體 v1.15.0（含測試版）起，裝置會回報自己支援的所有指令（`commands`）。後端在第一次收到該裝置的狀態時，於背景抓一次（每個韌體版本一次；`capabilities` 的指令表 hash 變了也會重抓），不會讓裝置閃燈。
- 有指令表時，「能不能下這個指令」和「需不需要維護模式」都依裝置回報判斷；沒有指令表的舊韌體照舊使用內建清單。
- 新 API：`GET /api/devices/<uid>/commands`（還沒抓到或舊韌體時回 `null`）。

## Terminal

- 新增「這台裝置的其他指令」分組：列出裝置支援、但 Desktop 還沒有專屬表單的指令，顯示韌體附的英文說明，參數以 `--key value` 自由輸入（數字與 true/false 自動轉型）。貼上這類指令也能辨識。
- 裝置標示為維護模式專用的指令，說明後面會加註「僅維護模式」。
- 新增 `commands` 指令。

## 相容性

- 舊韌體、舊 Hub、舊 Gateway 都能照常使用。

Companion firmware release: **New Horizons OS v1.15.0-beta.1** (beta channel; stable stays on v1.14.0).
