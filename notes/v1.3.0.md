# v1.3.0

**系統監視器可以操作了：結束、啟動工作與服務，查看系統執行緒與每核 CPU。新增可操作的 Panel App,App Studio 也能編寫。**

## 系統監視器

- 從 App Library 安裝新版「系統監視器」(sysmon v2.0.0,需要韌體 v1.19.0),分頁有:效能(loop 與每核 CPU、heap、掃描 fps 的歷史曲線)、工作、服務、App、系統執行緒。
- 每列的「⋯」選單可以結束／啟動工作、調整執行頻率、停止／啟動／重新啟動服務、停止／啟動／復活 App。每個操作都要先確認。
- 上方的「執行」框輸入名稱就能啟動已停止的工作、服務或 App(自動補完)。
- 所有停止只在本次開機有效，重開機後恢復。受保護的工作與服務由韌體拒絕，介面上會直接隱藏。
- 監視器每秒只送一個 `sysmon` 指令，透過 Hub 也不會塞車。

## Panel App

- 新的套件種類 panel:可以操作的 readout。它只能送出 manifest 宣告的權限(工作控制、服務控制、App 控制)允許的指令,`set_*`、寫檔、重開機、安裝等一律拒絕。
- 安裝和開啟時會列出它宣告的權限。裝置指令表沒有的操作(舊韌體)會自動隱藏。
- 操作條件:`when` 要全部成立才能使用,`hidden_when` 任一成立就隱藏；裝置沒回報的欄位不符合任何條件。

## App Studio

- 新增「新規パネル／New panel」,範本可以直接通過驗證。
- 建置頁顯示權限與操作數量，參考頁新增權限表與條件規則，匯出 `panel.json`。
- 模擬頁在選定的實機上預覽 panel(之前會被誤當成 flow),並提醒預覽中的操作會在裝置上真的執行。
- AI prompt 有 panel 專用版本。

## Terminal

- 新增 `task-stop`、`task-start`、`task-set-period`、`service-stop`、`service-start`、`app-stop`、`app-start`、`thread-list`、`sysmon`。

Companion firmware release: **New Horizons OS v1.19.0**.
