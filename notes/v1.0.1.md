# v1.0.1

**下拉選單和確認視窗全部換成 app 自己的樣式。設備檔案頁重新設計。更新日誌改成渲染 Markdown。電池容量新增 500／600／700 mAh 預設。另外修正夜晚主題的幾個顯示問題，登入頁也重新整理。**

## 下拉選單與彈窗

- 全 app 的下拉選單（38 處）改用自訂元件，跟著白天／夜晚主題變色，選中的項目有 ✓。
  - 選單會從按鈕往下展開，下方空間不夠時改往上。在彈窗或可捲動的區塊裡也不會被切掉。
  - 鍵盤操作跟原生的一樣：上下鍵移動、Enter 選取、Esc 關閉，直接打字可以跳到對應項目。
- 中繼頁刪除 Gateway／Hub 時，原本跳出的是瀏覽器內建的確認視窗，現在改成 app 自己的確認視窗。

## 設備檔案

- 改成跟 CSV 匯出相同的視窗：左邊是檔案範圍，中間是檔案清單（名稱、大小），右邊是預覽。
- 預覽 log 時會自動捲到最後，最新的內容在最下面。其他檔案的預覽直接提供下載按鈕。
- 儲存空間縮成底部的一條狀態列；下載、上傳進度也顯示在狀態列。
- 刪除檔案前會先確認。在使用者檔案範圍，上方會提示是否需要維護模式，並可以直接切換。

## 更新日誌

- 設備的「更新」分頁、Hub 管理視窗的更新日誌，改成渲染 Markdown（標題、粗體、清單）。
- Hub 的更新日誌原本只是連到 GitHub 上的原始檔案，現在可以直接在視窗裡展開查看。

## 電池

- 容量預設改為 200／400／500／600／700 mAh，選了容量就自動帶入充電電流：200 mAh 為 100 mA，400 mAh 為 200 mA，其他都是 350 mA。只有選「自訂」才需要自己輸入。
- 已存的設定如果不符合任何預設，會顯示成「自訂」。例如之前存的 400 mAh／100 mA，要改成新預設的話，請重新選「400mAh · 200mA」並儲存。

## 夜晚主題與介面修正

- 夜晚時頂部分頁、各處分段切換的選中狀態看不清楚，現在改用較亮的灰色標示。
- App Store 的分類按鈕在夜晚會變成白底白字，已經修正。
- 瀏覽器自動填入帳號密碼時，輸入框不再變成黃色。
- **登入頁**：拿掉左側的綠色區塊，只留一張登入卡片；「NH Console」改成淡淡的大字當背景，實驗室與大學名稱放在頁面底部。
- **關於視窗**：標題靠左；實驗室名稱和會津大學 logo 移到更新日誌下方並排。
- **概覽**：連線方式簡化為「Connected via NH Gateway／NH Hub」。

Companion firmware release: **New Horizons OS v1.17.0**.
