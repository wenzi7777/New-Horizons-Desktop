# v0.10.1

SDK 分頁改名為 **App Studio**，修正它每秒重新編譯造成的閃爍，並支援韌體 v1.3.0 的 24 個節點。

## 改名

這個分頁是編輯器、編譯器與模擬器合在一起的工作環境，不是 SDK。導覽列顯示「Studio」，頁面標題為
App Studio（アプリスタジオ／应用工作室），路徑改為 `/studio`，舊的 `/sdk` 會自動轉址。
「SDK」這個名字留給它所使用的 App Library 工具鏈。

## 修正：頁面每秒重新編譯

板型選擇某台裝置時，裝置清單每秒更新一次「最後上線時間」，讓板型每秒都變成新的物件，頁面便每秒
重新編譯一次 App：

- Build 分頁的 sha256 每秒清空再重算，因此一直閃爍；
- 即時模擬器每秒被重置，面板清空後捲動位置跳回頂端，同時重新訂閱串流、缺幀比例也算錯。

現在只在板型的格數改變時重新分析；模擬器以套件**內容**判斷圖是否改變（只改註解也不會重置）；即時
串流只隨開始／停止與裝置重新訂閱，畫面每 50 ms 重繪一次，但仍逐幀計算。

以 headless Chrome 對照驗證：修正前 sha256 在 4 秒內變動 8 次、即時模式 3 秒後捲動回到頂端；
修正後分別為 0 次與維持原位。

## 24 個節點

- 內建的 SDK 與後端的套件檢查允許 24 個節點；超過 12 個節點的圖需要 `min_os: v1.3.0`。
- 板型選的裝置韌體比 App 需要的版本舊時，Build 分頁改為「適用於 OS v1.3.0 以上」並說明裝置會拒絕
  它的原因，而不是顯示「可以安裝」。

## 其他

- Build 分頁的「裝置限制」新增說明：節點、開銷、窗口池、套件大小與每個 App 的執行時間各代表什麼。

## 驗證

Python 448 項、frontend 69 項全數通過；`npm run build` 通過。

Companion firmware release: **New Horizons OS v1.3.0**.
