# v1.17.0

**ビジュアライゼーションのカードに「転置」（X / Y 軸の入れ替え）を追加。Gyro / Acc をグラフィック表示にし、磁気センサーも表示します。**

## 転置

- 行ミラー / 列ミラーの隣に「転置」チェックを追加：行と列を入れ替えます（6 × 8 が 8 × 6 に）。サイズ表示、2D ヒートマップ、3D サーフェス、COP も追従します。
- 転置してからミラー：行 / 列ミラーは常に画面上の上下 / 左右を反転します。3 つの組み合わせで 8 通りの向きすべてになります（転置 + 列ミラー = 時計回り 90°）。
- 表示のみ：記録と CSV は変わりません。P 番号はセンサーに付いて動き、A.. / D.. ピン表示は軸と一緒に入れ替わります。設定はこのブラウザに保存されます。
- センサー配置プロファイルを選んでいる間は転置できません（プロファイルがセンサー位置を決めるため）。

## IMU と磁気センサー

- 数値行の Gyro / Acc を 3 つのパネルに置き換え：それぞれメーター + 直近 10 秒の X / Y / Z トレンド線（赤 / 緑 / 青、自動スケール）+ 同色の数値。
  - 加速度センサー：水準器（気泡は高い側へ）、|a| とロール / ピッチ。
  - ジャイロ：X / Y / Z の中央基準バー、スケールは 30–2000 °/s で自動切替。
  - 磁気センサー（新規）：ボード +X の方位を示すダイヤル（加速度で傾き補正）、µT の値と |B|。方位は生値で、精密なコンパスではありません。磁気センサーのないデバイスはその旨を表示します。
