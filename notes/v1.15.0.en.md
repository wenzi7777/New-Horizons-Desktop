# v1.15.0

**The Relays page shows cards only for online relays and gathers offline ones in an "Inactive relays" list; offline relays nobody signed in with are removed after 1 day.**

## Relays page

- NH Studio / NH Pocket / NH Studio headless, NH Hub and legacy Gateways all get cards only while online, signed-in apps first.
- Every offline relay is gathered under the "Inactive relays (n)" button at the bottom of the page, which opens a compact table (name, ID, version, sign-in, last seen, delete). "Remove offline" moved there too. Whether it is open is remembered in this browser.
- The section title "NH Studio / NH Pocket / NH Studio headless" is now "App relays", with the number online beside it.
- Cards no longer show "denied devices / UDP forwarded / UDP dropped" when they are 0; the upstream address is shown only for relays set to something other than production (local, manual).

## Offline relays removed sooner

- An NH Studio / NH Pocket / headless that never signed in is removed after 1 day offline (every fresh install or dev run makes a new relay ID, which is what made the list grow). Signed-in relays, NH Hubs and legacy Gateways keep 7 days.
- Set `NEWHORIZONS_UNAUTH_RELAY_OFFLINE_TTL_DAYS` to change it; 0 gives them the normal 7 days.
