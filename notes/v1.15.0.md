# v1.15.0

**Relays 頁面只用卡片顯示線上的中繼，離線的收進「非アクティブな中繼」列表；未登入的離線中繼 1 天就自動移除。**

## Relays 頁面

- NH Studio / NH Pocket / NH Studio headless、NH Hub 與舊版 Gateway 都只為線上的中繼顯示卡片，已登入的排前面。
- 所有離線的中繼收進頁面下方的「非アクティブな中継 (n)」按鈕，點開是一張精簡表格（名稱、ID、版本、登入狀態、最後連線、刪除）；「移除離線」按鈕也移到這裡。展開與否會記在這台瀏覽器。
- 區塊標題「NH Studio / NH Pocket / NH Studio headless」改為「應用程式中繼」，旁邊顯示目前幾台在線。
- 卡片不再顯示為 0 的「拒絕設備／UDP 轉送／UDP 丟棄」；上游位址只在中繼設成 production 以外（local、手動）時才顯示。

## 離線中繼自動清除

- 從未登入的 NH Studio / NH Pocket / headless 離線 1 天後自動移除（每次新安裝或開發執行都會產生新的中繼 ID，這些就是列表變長的主因）。登入過的中繼、NH Hub 與舊版 Gateway 維持 7 天。
- 可用 `NEWHORIZONS_UNAUTH_RELAY_OFFLINE_TTL_DAYS` 調整，設為 0 則與其他中繼相同（7 天）。

Companion firmware release: **New Horizons OS v2.3.1**.
