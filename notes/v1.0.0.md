# v1.0.0

**新增夜晚主題，依會津的日出日落自動切換，也可以手動切換。新增操作手冊（書本按鈕），Wiki 併入手冊。設備設定頁重新分組與設計，各頁面改得更緊湊。**

## 夜晚主題

- 頂部右側新增主題按鈕，每點一下依序切換：自動（半日半月圖示）→ 白天（☀）→ 夜晚（☾）。
- **自動**：依會津若松的日出日落時間切換。時間在瀏覽器裡計算，不需要網路，也不會詢問位置權限。滑鼠移到按鈕上會顯示下次切換的時間。
- 選擇的模式記在這台瀏覽器裡。重新整理頁面時直接套用上次的主題，晚上打開不會先閃白畫面。
- 夜晚配色是石墨灰（類似 macOS 深色模式），綠色只用在按鈕和狀態上。程式編輯器的語法顏色、資料分析的曲線也會跟著切換。

## 操作手冊

- 頂部右側新增書本按鈕，打開手冊頁，分成兩部分：
  - **Desktop 指南**：6 章，介紹開始使用、連接設備、設備與設定、即時顯示與錄製、錄製資料與分析、配置與應用。依介面語言顯示英文、日文或簡體中文。
  - **設備 Wiki**：原本的 Wiki 頁面。
- 頂部的 Wiki 頁籤已經移除，舊的 `/wiki` 網址會自動轉到手冊。

## 設備設定頁

- **分頁重新分組**，依使用頻率排列：概覽、維護、應用、硬體、數據流、更新、診斷、檔案、實驗性。
  - Action Button 併入硬體，時鐘併入數據流（原本的「運行時」）。
  - 韌體更新獨立成「更新」分頁。
- **頁首**：原本的四張大卡片改成一行，顯示設備名稱、在線狀態、型號、韌體、連線方式，右側是模式切換。
- **每個分頁只突出重點**：
  - 讀回的數值改成清單；原始數值和不常改的設定收進「詳細資料」或「進階」，點一下才展開。
  - 板子不支援的功能直接隱藏，不再顯示「此板不支援」卡片。
  - **概覽**：上方是電量和連線方式。重新啟動移到最下方，並且需要確認。
  - **硬體**：依序為電池與充電、電源、Action Button、燈光與顯示，腳位配置放在最後的「進階」。
  - **數據流**：掃描速率以三個預設為主，只在設定和設備目前的值不同時，才能按「套用」。
  - **更新**：顯示「已安裝 → 可更新」版本，有新版時才出現「安裝」。
  - **檔案**：清除日誌需要確認。
- 操作結果的提示改成置中在畫面下方，有圓形狀態圖示，底邊的色條會倒數到提示自動關閉。只是重複指令名稱的結果，改顯示「完成」。

## 其他介面

- **登入頁**：改成左右分欄，左邊綠色區塊寫 NH Console、實驗室與會津大學，右邊只有登入表單。原本的說明文字移除。
- **關於視窗**：標題改為 NH Console，下一行是版本號。
- **首頁**：移除「Discovered Devices」標題和 Global Apps 區塊。
- **頁面高度**：所有頁面的標題緊貼上方，內容少的頁面也不會被撐高。
- **可視化**：
  - 工具列和設備卡片上半部改得更緊湊。
  - Range 改成預設選單，有 300–3150（預設）和 300–4990，選「自訂…」可以自己輸入。
- **中繼**：
  - Gateway 和 Hub 的卡片改得更緊湊，寬螢幕時兩張並排。
  - 設定說明移到頁面最下方，Gateway 和 Hub 各三個步驟。
- **App Store** 和設備的 App 頁改為全寬。商店目前只列出 7 個 App。
