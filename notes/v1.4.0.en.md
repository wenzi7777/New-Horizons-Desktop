# v1.4.0

**Server support for NH Studio and NH Pocket. NH Studio replaces the software Gateway.**

## Relays page

- The "Gateway" section is now "NH Studio / NH Pocket" and shows Studio, Pocket or Hub by connection type.
- The old Python Gateway still connects; it is listed under "Legacy Gateway" with a pointer to NH Studio.
- The download button goes to the new download page (New Horizons Studio / New Horizons Studio Pocket).
- Each Studio / Pocket card shows whether it is authenticated.

## Sign in with a Desktop account

- NH Studio, NH Pocket and Studio headless sign in with a Desktop user name and password. The password is checked once and the server issues a token for that computer or phone, with the account's role; no session is created and the password is not stored.
- The tokens are listed under "App tokens" on the Relays page with their account and device, and an admin can revoke them. Signing out of the app revokes its own token.
- Admins can still create a token directly on the Relays page.

## Sync

- Recording upload: chunked and resumable, stored in the usual folder layout, visible on the Files page, with its source recorded.
- Device nicknames, groups and profiles sync both ways (the latest change wins).
- The server's FindMe answers no longer take devices that a Studio, Pocket or Gateway manages.

Companion firmware release: **New Horizons OS v1.19.1**.
