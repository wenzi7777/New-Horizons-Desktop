# v1.14.1

**When a Vref sweep cannot compute Rs it now says why; every UI animation now uses an easing curve.**

## Vref sweep (TIA-CTL v2.0.F)

- When Rs comes out at fewer than two steps (no cell read more than 30 mV above Vref at the other steps), the panel no longer says "measure Rfb". It asks you to keep the pressure the same for the whole sweep and suggests checking in the CSV that `raw_mv` rises with Vref.
- The old message appears only when there is no Rfb at all (not measured and no soldered value). The soldered Rfb is used only for rows without a measured one.

## Animation

- Transitions and animations that used default curves such as `ease` now use shared easing tokens (`--ease-out`, `--ease-in-out`, `--ease-in`).

Companion firmware release: **New Horizons OS v2.3.1**.
