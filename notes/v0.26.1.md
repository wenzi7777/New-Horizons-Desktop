# v0.26.1

**修正：使用韌體 v1.16.0 時，App 一產生事件（例如磁鐵靠近 compass），網頁的即時串流就停住，要重新整理才恢復。CSV 匯出的裝置清單在後端重新部署後變成空的。**

## 修正

- **即時串流停住**：韌體 v1.16.0 會把 App 事件放在感測器封包裡送出。後端解析出的內容含有二進位資料，轉成 JSON 推給瀏覽器時失敗，WebSocket 因此被關閉，畫面停在最後一格。現在改用十六進位字串表示；萬一還有無法轉成 JSON 的資料，也只略過那一筆，不會再關閉連線。錄製檔不受影響。
  - 更早的 Desktop 版本也有同樣問題，只是以前沒有韌體送這種資料。**請先把 Desktop 更新到這一版，再讓裝置更新到韌體 v1.16.0。**
- **CSV 匯出的裝置清單**：以前只列出目前連線中的裝置，所以後端剛重新部署、裝置還沒連上時，清單是空的，但檔案其實都還在。現在直接列出伺服器上有錄製資料夾的所有裝置，依最近修改時間排序；未連線的裝置圖示會變淡。新增 API `GET /api/files/devices`。

Companion firmware release: **New Horizons OS v1.16.0-beta.1** (beta channel).
