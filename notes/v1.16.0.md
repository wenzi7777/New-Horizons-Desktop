# v1.16.0

**新增「插圖」介面：設備總覽是一張板子圖，即時數值用引線標在實際的零件旁；預設仍是經典介面，可在頂欄切換。**

## 插圖介面（v2.0.F / v1.5.F / v1.0.F）

- 頂欄語言選單旁新增「介面」選單（經典／插圖），記在這台瀏覽器。預設經典，與以前相同。
- 設備設定 → 總覽：板子的向量圖（依 PCB 檔的實際位置，隨亮色／深色主題變色），兩側是可點的數值——電池、讀數模式、掃描 FPS 與矩陣、連線、韌體、燈號；點一下跳到對應的設定區段。掃描與腳位合成一個「矩陣」標籤，引線分岔到兩個 FPC。
- 電源與連線路徑：USB-C／電池 → 充電 → 系統、設備 → 中繼 → 伺服器，正在使用的路徑以實線標示。
- IO Visualizer：兩個 FPC 的放大圖，每支腳一個方塊，已啟用的亮起。
- 讀數模式、掃描預設、更新通道改用大型選項按鈕（選中打勾），一樣按「套用」才送出。
- GCU LTS 板沒有插圖，維持原本的卡片。

## 其他

- 修正 v1.5.F / v2.0.F 數位 FPC 的腳位標示：接點 18 = GND、17 = SCL（GPIO 42）、16 = SDA（GPIO 40）、15 = NC（以前錯置）。
- 電池圖示充電時，閃電畫在電池裡面並加挖空外框，更明顯。
- IO Visualizer 的板子圖限制在 460 px；Vref 面板顯示 v2.0.F 背面 Rfb0–13 的位置與哪些已焊上（依 rfb_measure 結果）。
