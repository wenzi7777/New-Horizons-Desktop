# v1.10.0

**NH Studio / NH Pocket 改用帳號自動登入，Relays 頁不再有 App token 管理；卡片按鈕不再超出卡片。**

## 登入

- Relays 頁移除「已登入的應用（App token）」分區。NH Studio / NH Pocket 會記住登入的帳號，每次啟動自動重新登入，不需要再手動撤銷或管理 token。
- Relays 頁的 NH Studio / NH Pocket 卡片改顯示「已登入：帳號」或「未登入」；NH Studio headless 與 NH Hub 不需要登入，不顯示。
- 同一台 App 重新登入時，伺服器會讓它之前的 token 失效；30 天沒使用的 token 也會自動失效，不會再越積越多。

## 修正

- Relays 頁卡片寬度不夠時，「管理」「刪除」按鈕改為換到下一行，不會再超出卡片。

Companion firmware release: **New Horizons OS v1.23.0**.
