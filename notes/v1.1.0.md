# v1.1.0

**Hub 也有「需要更新」了：Backend 會告訴 Hub 最新版本；落後時，Hub 繼續轉發已配對的設備，但設定與新設備會被鎖住，閒置時自動更新。**

## Backend

- Hub 連上時，`gateway_hello_ack` 會帶 `latest_hub_version`：依 Hub 自己的更新通道（stable / beta）讀 Hub 的 manifest，快取 5 分鐘。Gateway 收到的內容不變。
- 新增 `hub_version_check` → `hub_version`：一直連著的 Hub 每 30 分鐘會再問一次，不必等重開。
- 可用 `NEWHORIZONS_HUB_LATEST_MANIFEST_URL`、`NEWHORIZONS_HUB_BETA_MANIFEST_URL`、`NEWHORIZONS_HUB_LATEST_VERSION_CACHE_SEC` 覆寫。

## Hub 管理視窗

- Hub 需要更新時，視窗頂端顯示提示：哪一版已發布、目前鎖住什麼、何時會自動更新。自動更新失敗時改成「約 30 分鐘後重試」。
- 需要更新期間，「連線」的儲存按鈕與「搬移到 Hub」按鈕停用。
- 「最新版本」與「有可用更新」在還沒按「檢查更新」前，也會依 Hub 回報顯示。

## 中繼頁

- Hub 卡片顯示「需要更新（版本）：閒置時自動更新」。

## 相容性

- 需要 Hub v0.12.0 才會鎖定與自動更新；舊版 Hub 會忽略新欄位，照舊只在開機時更新。

Companion firmware release: **New Horizons OS v1.17.0** / **New Horizons Hub v0.12.0**.
