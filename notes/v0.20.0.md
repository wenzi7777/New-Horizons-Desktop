# v0.20.0

## 感測器編號統一（以 CSV 為準）

以前校正畫面和 CSV 的編號**順序不同**：CSV／串流是逐列排（列 × 欄數 + 欄）、從 P1 開始；校正是逐欄排（欄 × 列數 + 列）、從 P0 開始。所以校正畫面的「P31」和 CSV 的「P32」並不是同一顆感測器。

- 校正畫面的矩陣格子、「取得 P#」按鈕、無法擬合清單、飽和清單、等級標註，全部改用 CSV 的編號（逐列、從 P1 開始），清單也照這個編號排序。
- 可視化、Profile 的預設標籤、匯入 profile 的預設標籤也改從 P1 開始。已存的自訂標籤不變。
- 韌體和校正指令內部的編號不變，已存的校正資料不受影響。

## 可視化 2D 顯示編號

- 熱圖每格左上角顯示 P 編號，格子太小時不顯示。
- Profile 圓點模式在數值上方顯示編號。
- 修正：開啟鏡像翻轉時，2D 的編號原本會標到錯誤的感測器。

## 經 Hub 連線的裝置斷線判斷

以前裝置斷電後，只要有頁面在定期查詢它（例如設定頁），就會一直顯示在線：Hub 回報的「送達逾時」被當成裝置剛回應。

- 後端：Hub 或 Gateway 代為回報的失敗（`command_delivery_timeout`、`result_page_timeout`、`device_not_connected_to_hub` 等）不再算作裝置在線。舊版 Hub 也適用。
- 搭配 Hub v0.8.0：Hub 超過 15 秒沒收到裝置封包，會明確回報斷線，裝置斷電後約 15–20 秒就會顯示離線。

## Relays：Hub 管理

- **Hub 卡片可以刪除**，和 Gateway 相同。仍在運作的 Hub 下次連上時會重新註冊。
- **Hub 管理改成獨立頁面**（`/gateways/hub/<id>`），排版和裝置設定頁一樣：上方四張概覽卡（狀態、韌體版本、網路、配對裝置），左側分頁列：
  - **概要**：MAC、IP、頻道、連線目標，以及服務中的裝置（可直接進入該裝置的設定頁）。
  - **連線**：連線目標設定，儲存後 Hub 會重開。
  - **時計**：Hub 的時鐘狀態與立即同步。
  - **韌體更新**：目前／最新版本、「檢查更新」、「立即更新」與發布說明連結。更新完成、失敗或逾時都會提示。需要 Hub v0.8.0；舊 Hub 會提示需要更新，開機時的自動更新照常。
  - **裝置**：配對中的裝置；掃描同網路的 WiFi 裝置並移到這個 Hub。
  - **維護**：工廠重置、刪除 Hub。
- 原本的「管理」彈出視窗已移除。

## 校正

- 等級卡片整張都可以點擊選取，不再只能點左側的等級名稱。刪除按鈕只會刪除，不會順便選取。
