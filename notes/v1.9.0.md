# v1.9.0

**停用舊的 NH Gateway，伺服器的 FindMe 回應改為新版格式，配合 NH Studio / Pocket / headless 互相接管設備。**

## 中繼

- 舊的 Python NH Gateway 不再能連上伺服器：連線時會收到「請改用 NH Studio（或 NH Studio headless）」並被中斷，也不會出現在 Relays 頁。
- Relays 頁的「接管」對 NH Studio / NH Pocket 也能生效（以前設備轉過去後收不到回應，claim 會逾時）。

## FindMe

- 伺服器直接回應設備時改用第 2 版 offer，附上目前直接連線的設備數，新版韌體依此挑選負載較輕的中繼。

Companion firmware release: **New Horizons OS v1.23.0**.
