# v0.6.10

## Visualize 卡片電池資訊

- 設備卡片標題列新增電池顯示：圖示、百分比，hover 顯示預估剩餘時間；充電時
  改為顯示預估充滿時間，充飽顯示已充滿。
- 僅具 MAX17048 電量計的 v1.5.F 顯示實際電量；其他板子顯示「不支援」佔位，
  卡片版面在各硬體間保持一致。
- 新增低電量警報：依板子設定的閾值，未充電且低於閾值時電池顯示轉為紅色並
  脈動，條件與韌體 `BatteryLedPolicy` 的板載 BAT LED 完全一致（閾值 0 代表
  停用、充電中不告警）。警報以靜態紅色成立，開啟「減少動態效果」時仍清晰可見。
- 電量計重新同步期間不顯示過期讀數，也不會據此誤報低電量。

## Visualize 新增設備彈窗

- 彈窗先前顯示的是**運作模式**而非連線狀態，一台已斷線的設備仍顯示 `normal`；
  現在顯示真實的在線 / 啟動中 / 重連中 / 離線狀態，並附狀態圓點。
- 先前顯示的 `last_seen_at` 會被 gateway 對已斷線設備持續刷新，等於恆新的假
  時間，且未經格式化；現在改用與其他頁面一致的 `last_live_seen_at` 來源與
  友善格式。
- 資訊補齊至與 Launchpad 卡片相同：硬體型號、韌體版本、協定、電池、矩陣、
  傳輸方式。
- 在線設備排在最前、離線排最後並調暗；連線狀態逾時後清單會自動重新排序，
  不需重開彈窗。
- 新增搜尋框（名稱 / 暱稱 / UID，可輸入 `AA:BB` 或 `aabb`），捲動清單時搜尋列
  與標題不會被捲走；關閉彈窗時自動清空。

## VD-CTL/R v2.2.C GCU LTS 板型修正

- `v2.2.C` 先前不在前後端的 board profile 表中，會退回 v1.0.F 預設值，被誤判
  為具有充電控制、OLED、外部 LED 與本機電源鍵——這些它都沒有。
- 前後端皆補上正確的 v2.2.C profile（11×13 矩陣、自有 OTA track），能力旗標
  對齊韌體 `BoardConfig.h`。
- 該版本尚無板卡照片，IO Visualizer 改為顯示板名文字，不再借用其他板型的圖。

Companion firmware release: **New Horizons OS v0.17.7**.
