# v0.10.2

修正：裝置名稱在 `NHOS-<UID>` 與 `<UID>` 之間不斷來回變化。

## 問題

凡是列出裝置的地方，名稱都會在兩者之間跳動；在 App Studio 的 readout 預覽裡最明顯。

readout 預覽每秒輪詢裝置一次，而大多數命令結果（`memory_status`、`app_list`…）不帶
`device_name`。後端遇到沒有名稱的訊息時退回成 UID，把裝置改了名；下一次 status 或
heartbeat 又改回 `NHOS-<UID>`。

## 修正

訊息沒有帶名稱時，後端不再更動既有的名稱；從未回報過名稱的裝置仍以 UID 顯示，裝置真正改名時
照常更新。串流路徑原本針對這個情況的特例，已由這條通則取代並移除。

## 驗證

Python 452 項（新增 4 項名稱穩定性測試，修正前會失敗）、frontend 69 項全數通過；
`npm run build` 通過。
