# v1.5.0

**NH Studio headless を Hub と同じ扱いにしました。接続の種類に応じて NH Studio / NH Pocket / NH Studio headless / NH Hub と表示します。**

## NH Studio headless

- 新しい接続種別 `relay`：Hub と同じく、サインイン不要で中継だけを行い、録画はしません。Relays ページでは NH Studio / NH Pocket の欄に「NH Studio headless」として表示されます。
- 旧 Python Gateway もこれまでどおり接続でき、「旧 Gateway」の欄に NH Studio への移行案内つきで表示されます。

## 表示名

- デバイス画面の「Connected via NH Gateway」は、実際の中継の種類に応じて NH Studio、NH Pocket、NH Studio headless、NH Hub と表示します。

## Relays ページ

- 「トークンを作成」フォームを削除しました。アプリは Desktop のアカウントでサインインします。サインイン済みアプリの一覧と取り消しボタンだけが残ります。

## 中継性能テスト

- `POST /api/relay-bench` を追加：NH Studio / NH Pocket の「中継性能」テストがサーバーへのアップロード速度を測るのに使います（受け取った内容は破棄、最大 16 MB）。

Companion firmware release: **New Horizons OS v1.20.0**.
