# v1.12.0

**Support for New Horizons OS v2.1.0: apps are written in a TypeScript-style language, and installing one lists its dangerous capabilities and asks for consent.**

## Device apps

- The device's apps moved into its settings (Settings → Apps); the separate device-apps page is gone (old links redirect).
- Laid out like a phone's background-apps screen: memory and CPU bars with a colour per running app and how many more would fit; a card per running app with what it draws on the OLED / LED, its load (with a one-minute sparkline), memory and CPU; every other app as a row with a switch. A row says up front when the app would not fit.
- Tap an app for its details: load over 1 s / 10 s / 60 s, borrowed time, permissions, recent events of that app only, and pause / resume, revive, move first (wins shared display rows), App Store and uninstall.
- No more slots or maintenance switch: turning an app on or off enters maintenance mode and leaves it again by itself (scanning pauses for about a second); while recording, it asks first.
- Terminal: `app-reorder` added; `app-enable`, `app-disable`, `app-load-flow` and `app-unload-flow` removed (firmware v2.1.0 no longer has them).

## App Studio

- Source is now `app.ts`, a subset of TypeScript (`let/const`, functions, `if`/`while`/`for`, `Float32Array`, `on("frame", …)` events); the old `.nhs` syntax is no longer accepted. The editor uses TypeScript highlighting and completion, and errors are marked at their line and column.
- The reference panel is generated from the SDK's `nhos.d.ts`: every API with its signature and description, with the ones that need the operator's consent marked.
- New template, AI prompt and README for the new language; the build panel shows memory use (pool bytes), the app's state variables and the capabilities that need consent. Apps with loops show no per-frame cost estimate.
- The emulator runs the bytecode itself: heatmap regions and highlighting the line whose event fired work as before.

## Installing

- When an app declares dangerous capabilities (storage, device settings, streaming, external I2C / UART), the install dialog explains them and installs only once you tick the consent, sending it to the device as `grant`.
- When the board lacks the external I/O an app needs (I2C / UART are on v1.5.F and v2.0.F only), the dialog says so before anything is written.
- New error messages `capability_not_granted` and `capability_unsupported`; app packages are validated by their `vm` (`nodes` no longer required).

## Device files

- New "App Data" scope to browse and download the CSV files apps write with `store.append`.

Companion firmware release: **New Horizons OS v2.1.0** (App Library 3.0.0).
