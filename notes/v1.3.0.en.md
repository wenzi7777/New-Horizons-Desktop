# v1.3.0

**The system monitor can now act: end and start tasks and services, and see system threads and per-core CPU. New Panel Apps that can act, which App Studio can also write.**

## System monitor

- Install the new System Monitor (sysmon v2.0.0, needs firmware v1.19.0) from the App Library. Tabs: Performance (history charts of loop and per-core CPU, heap and scan fps), Tasks, Services, Apps and System threads.
- Each row's "⋯" menu ends or starts a task and changes how often it runs, stops, starts or restarts a service, and stops, starts or revives an app. Every action asks for confirmation first.
- The Run box at the top starts a stopped task, service or app by name, with autocomplete.
- Every stop lasts until the next reboot. The firmware refuses protected tasks and services, and the monitor does not offer them.
- The monitor sends a single `sysmon` command per second, so it does not clog a Hub.

## Panel apps

- New package kind panel: a readout that can act. It may only send the commands its declared permissions (task control, service control, app control) allow; `set_*`, file writes, reboots and installs are always refused.
- Its permissions are listed when it is installed and when it is opened. Actions the device's command catalog lacks (older firmware) are hidden.
- Action conditions: `when` must hold in full for an action to be usable, any one `hidden_when` hides it, and a field the device does not report matches no condition.

## App Studio

- New "New panel", with a template that validates as written.
- Build shows the permissions and action count, Reference adds the permission table and condition rule, and export writes `panel.json`.
- The emulator previews a panel on the chosen device (it used to be mistaken for a flow) and warns that actions in the preview really run there.
- The AI prompt has a panel version.

## Terminal

- New `task-stop`, `task-start`, `task-set-period`, `service-stop`, `service-start`, `app-stop`, `app-start`, `thread-list` and `sysmon`.

Companion firmware release: **New Horizons OS v1.19.0**.
