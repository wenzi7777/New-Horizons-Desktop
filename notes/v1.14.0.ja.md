# v1.14.0

**TIA-CTL v2.0.F の基準電圧パネルが 3 種類の読み取りモード（ADC mV、電導 µS、電導＋スマート Vref）になり、電導モードでも校正できます。記録にはフレームごとの単位・Vref・飽和行が加わりました。**

## 読み取りモード（TIA-CTL v2.0.F）

- 基準電圧パネルの読み取りは 1 つの選択肢になりました：ADC mV（既定）、電導（µS）、電導＋スマート Vref。「適用」で送信します。「基準スケールへの換算」と基準 Rfb は削除しました。
- 電導には先に Rfb の測定が必要です。Rfb 表は行ごとの状態（正常、未実装、飽和、開放、ADC 失敗）を表示し、未測定の行があるときはそれらが 0 を出力することを示します。
- リーク補償は選択肢＋「適用」になりました。

## 記録

- デバイスがフレームごとのレンジ情報を送ると、CSV に `range_unit`、`vref_mv`、`saturated_rows` の 3 列が加わります。
- `.meta.json` の range は読み取りモード、出力単位、スマート Vref の有無、Vref、Rfb、offset、行ごとの状態を記録し、calibration には校正プロファイルの単位（`unit`）が加わりました。記録の概要には読み取りモードを表示し、旧ファームウェアの virtual / auto は「旧 virtual」と表示します。

## 校正

- 校正ワークベンチにプロファイルの単位を表示します。プロファイルと現在の出力単位が違うときは「保持するが適用しない」ことと、戻す方法・校正し直す方法を示し、電導モードでは Vref が変わっても校正が有効なことを示します。
- Rfb のない行のセンサーはフィット失敗に数えず、進捗は Rfb のあるセンサーだけで数え、除外した数を表示します。
- 新しいエラーメッセージ：校正中に出力単位が変わった、プロファイルの単位が違う。
