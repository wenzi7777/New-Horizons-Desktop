# v0.25.0

**CSV 匯出改成 Finder 樣式的檔案總管；Profile 編輯器重新排版；安裝 App 時的設備卡片與可視化一致；Relays 一行一張卡片。**

## CSV 匯出

- 改成 Finder 視窗的樣式：左側是裝置清單，中間是清單，右側是預覽，底部是路徑列和狀態列。
- 清單有「名稱／修改日期／大小／種類」四欄，點欄位標題可以排序，資料夾固定在最上面。可以搜尋目前資料夾。
- 選一個檔案就自動顯示預覽，不必再按「Preview」。雙擊資料夾會打開，雙擊檔案會直接下載。
- ⌘ 點擊、Shift 點擊可以多選，多選後可以一次下載或刪除。
- 鍵盤操作：↑↓ 移動選取、⌘↑ 回上層、⌘[ ⌘] 上一頁／下一頁、⌘A 全選、⌘⌫ 刪除。
- 刪除前改用 App 內的確認框，不再用瀏覽器的確認視窗。
- 檔案清單 API 多回傳修改時間（`modified_ms`）。

## Profile 編輯器

- 修正「預設視圖」右側多出一個空白格，看起來像有第三個選項。分段按鈕現在依選項數量分欄，外觀也改成 macOS 的樣式；裝置設定頁的掃描 FPS、可視化的 2D／3D 切換也一併套用。
- 版面改成「左側清單＋中間畫布＋右側檢閱器」：
  - 設定檔改為左側清單，下方有 ＋／− 按鈕。
  - 名稱、預設視圖、壓力範圍、點大小、背景圖移到右側檢閱器，畫布變大。
  - 匯入、匯出、儲存移到右上角，儲存結果顯示在按鈕旁，幾秒後自動消失。
- 工具列改成有圖示的分段按鈕，縮放顯示百分比。原本寫死英文的「Pan／Fit／Zoom／Cursor」改為翻譯文字。
- 感測器列表加上欄位標題；刪除設定檔和清空感測器前會先確認。

## 其他

- App Store 安裝 App 時，選擇設備的卡片和可視化「新增裝置視圖」的卡片相同（共用元件），會顯示電量、傳輸方式等資訊。
- Relays 頁的 Gateway 和 Hub 卡片改成一行一張。
- 補上原本沒有定義的強調色變數 `--accent-strong`，有幾處強調色先前沒有生效。
