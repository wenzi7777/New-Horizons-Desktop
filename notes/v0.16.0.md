# v0.16.0

**Device Settings 的診斷頁新增「設備健康」卡片。** 卡片顯示韌體 v1.9.0 的 SMART 式壽命統計，例如累計通電時數、重置次數、OTA 歷史和溫度。

## 設備健康卡片

- 位置在 **Device Settings → 診斷** 最上方。第一次打開這一頁時會自動讀取，之後按「刷新」手動更新。
  - 自動讀取是背景指令，不會讓設備閃燈。
  - 如果這時頁面剛好在刷新 status，會在 2 秒後重試，最多 3 次。
- **總評燈號**：正常（綠）、注意（黃）、異常（紅）。不是「正常」時，會列出原因：
  - 最近 10 次開機內有當機；
  - 有更新被回滾；
  - 晶片溫度偏高；
  - 可用記憶體曾非常低；
  - 連續開機失敗，已進入安全維護模式。
- **時間**：累計通電、運行中、軟關機、感測器掃描時數、本次開機、最長連續運行。以 `1,234 h 56 m` 格式顯示。
- **開機與重置**：開機次數、當機次數、上次重置原因，以及每種重置原因的次數。
- **韌體**：開始記錄時的版本、版本變更次數、OTA 成功與回滾次數。
- **環境與連線**：晶片目前、最高、最低溫度，最低可用記憶體，Wi-Fi 斷線次數。有按鍵的板子另外顯示按鍵次數。
- 卡片底部註明從第幾次開機開始記錄，以及「每 10 分鐘保存一次，斷電最多損失這段時間」。
- 韌體比 v1.9.0 舊時，卡片會提示更新韌體。

## 終端機

- 新增 `health` 指令，放在指令清單的檔案群組，在 `crash-log` 旁邊。
- 後端允許清單和模式設定也加上 `health`，一般模式和維護模式都能執行。

## 驗證

- Python（483）、frontend（91）測試全數通過；`npm run build` 通過。
- **尚未在瀏覽器與實機上驗證**：接上 v1.9.0 的裝置，診斷頁應該顯示健康卡片；接上舊韌體的裝置，應該顯示更新提示。

## 相容性

- 不改變既有指令或資料格式。舊韌體收到 `health` 只會回 `unknown_command`。

Companion firmware release: **New Horizons OS v1.9.0**.
