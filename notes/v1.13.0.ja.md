# v1.13.0

**基準電圧 (Vref) を「手動 + 2 つのスイッチ」に変更し、録画ファイルに v2.0.F の読み取り方式を記録します。FindMe カードが 2 つの値の間で切り替わらなくなりました。**

## 基準電圧 (TIA-CTL v2.0.F)

- Raw / 仮想 Rfb / 自動 の 3 つのボタンを 2 つのスイッチにしました。「基準スケールに換算」（仮想 Rfb）と、その上の「スマート Vref 調整」（自動）です。両方オフが手動（Raw）で、v1.5.F 以前の基板と同じ読み方です。換算には Rfb の測定が必要で、スマート調整は読み値のスケールを保つため換算がオンのときだけ使えます。ファームウェアの 3 つのモードは変わりません。
- 手動では従来どおり Vref スライダーと安全帯を表示し、手動かつ 330 mV のときは「v1.5.F 以前の基板と同じスケール」と表示します。スマート調整中はロックされたスライダーの代わりに、現在の Vref と起動後の調整回数を表示します。
- 基準 Rfb と GPIO45 の漏れ補正は「詳細設定」に移し、Rfb 測定・校正スイッチ・上限・Vref スイープと同じ場所にまとめました。

## 録画

- `.meta.json` に `range` を追加しました：`mode`、`vref_mv`、`ref_rfb_ohm`、`leak_compensation`、行ごとの `rfb_ohm` と `offset_mv`。v2.0.F のみで、他の基板は `null` です。録画中にモード・Vref・基準 Rfb・漏れ補正を変えると `changes` に記録されるので、どの区間が旧基板のデータとそのまま比べられるか後から分かります。

## FindMe

- デバイス設定の FindMe カードが 2 つの値の間で切り替わらなくなりました（Gateway ホストがデバイス自身の IP と relay の IP、最終成功が時刻と数値の間で変わっていました）。relay のスナップショットが、デバイスが relay のアドレスと起動後ミリ秒を報告するのと同じ欄に、デバイスの IP と時刻を書いていたためです。relay 側の値は `device_addr`、`last_findme_at` に保存します。
- 「最終成功」は「起動後 N 秒」と表示します。

## デバイス設定

- オン/オフの設定（IMU、ストリームバッファ、カスタム Manifest、起動時の自動更新、Log、フィルター、Raw ADC、漏れ補正、外部 LED モード）を、アプリと同じスイッチにしました。
- IO ビジュアライザーに v2.0.F の基板図を追加しました。
- アプリ：実行中カードに OLED とステータス LED に加えて外部 LED ストリップを表示します（`drive_ext_led` 権限のあるアプリ）。複数のアプリが点灯させうるときは「共有」、外部 LED モードが App でないときは実機では点灯しない旨を表示します。ボタンのアイコンを中央に揃えました。
