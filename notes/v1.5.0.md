# v1.5.0

**NH Studio headless 改為和 Hub 同一個地位；各處依連線種類顯示 NH Studio / NH Pocket / NH Studio headless / NH Hub。**

## NH Studio headless

- 新的連線種類 `relay`：不需要登入、只負責轉送、不在本機錄製，和 Hub 一樣。Relays 頁列在 NH Studio / NH Pocket 區塊，名稱是「NH Studio headless」。
- 舊版 Python Gateway 照常可以連線，顯示在「舊版 Gateway」並提示改用 NH Studio。

## 顯示名稱

- 裝置畫面的「Connected via NH Gateway」改為依實際的轉送種類顯示：NH Studio、NH Pocket、NH Studio headless 或 NH Hub。

## Relays 頁

- 拿掉「建立 token」表單：App 一律用 Desktop 帳號登入。只保留已登入的 App 清單和撤銷按鈕。

## 轉送效能測試

- 新增 `POST /api/relay-bench`：NH Studio / NH Pocket 的「轉送效能」測試用它量測到伺服器的上傳速度（內容讀取後丟棄，最大 16 MB）。

Companion firmware release: **New Horizons OS v1.20.0**.
