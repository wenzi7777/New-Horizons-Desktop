# New Horizons Desktop v0.4.15

## Changes

### IMU sample rate now shown accurately, with a hint that it follows scan rate

- The IMU Diagnostics card's "Sample rate Hz" metric was a dead placeholder
  (device firmware always reported a hardcoded `100`). Firmware v0.11.1 now
  reports the real value, so this metric is live.
- Added a hint under the metric clarifying that the IMU sample rate isn't
  independently configurable — it mirrors the matrix scan rate, adjustable via
  Scan Timing. Translated for English, Japanese, and Simplified Chinese.
- Mock/demo devices now mirror `imu.sample_rate_hz` from the mock's
  `scan_timing.target_fps`, matching real firmware behavior, so this is also
  visible without physical hardware.

## Verification

- `python3 tests/test_device_settings_page_static.py` — passes.
- `npm run build` — passes.
- Verified in-browser against a mock `VD-CTL/R v2.3.D GCU LTS` device: sample
  rate reads 60 at default scan timing, updates to 90 immediately after
  applying a 90 FPS scan timing change, and the new hint text renders.
