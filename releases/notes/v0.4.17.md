# New Horizons Desktop v0.4.17

## Changes

### CSV data now stored directly on host filesystem

- Docker Compose persistence changed from a named volume (`newhorizons_data`)
  to a bind mount (`./data:/data`). CSV recordings now land directly in
  `data/mqtt_store/<device_uid>/<YYYYMMDD>/<HHMMSS>.csv` on the host,
  accessible from Finder without going through Docker Desktop or the Web UI.
- Container path `/data/mqtt_store` is unchanged — no application code
  needed to be modified.
- Note: data previously stored in the named volume needs manual migration:

  ```
  docker run --rm -v newhorizons_data:/data -v $(pwd)/data:/backup alpine cp -r /data/. /backup/
  ```

### Default pressure range widened to 300–3150

- The Visualization page toolbar range inputs now default to Min=300,
  Max=3150 (was 300–1000) to match the actual sensor output range.
  Clicking "Reset" restores this new default.

## Verification

- `npm run build` — passes.
- `docker compose up -d --build` — container starts, CSV appears in
  `./data/mqtt_store/` when recording is active.
- Visualization page shows default range 300–3150, Reset button works.
