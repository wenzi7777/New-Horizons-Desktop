# New Horizons Desktop v0.4.17

## Changes

### Default pressure range widened to 300–3150

- The Visualization page toolbar range inputs now default to Min=300,
  Max=3150 (was 300–1000) to match the actual sensor output range.
  Clicking "Reset" restores this new default.

### Docker bind mount for direct CSV access

- Docker Compose now uses a host bind mount (`./data:/data`) instead of a
  named volume for `/data`. CSV recordings land directly in
  `data/mqtt_store/<device_uid>/<YYYYMMDD>/<HHMMSS>.csv` on the host,
  accessible without going through Docker Desktop or the Web UI.
- If you deploy behind a reverse proxy with `127.0.0.1` port binding and
  a custom network, update your `docker-compose.yml` `volumes:` section
  from `- newhorizons_data:/data` to `- ./data:/data` and remove the
  top-level `volumes: newhorizons_data:` block.
- Old named volume data can be migrated with:
  ```
  docker run --rm -v newhorizons_data:/data -v $(pwd)/data:/backup alpine cp -r /data/. /backup/
  ```
